# 两起死亡，从旅馆门后开始｜迷案解码人·第十一期

雨后的水踰洞，连着两起死亡。金素英，案发时二十岁。

最早的幸存者是她当时的男友：2025年12月，他在南杨州咖啡馆外昏迷，两天后醒来、分手并报案。后来进入水踰洞汽车旅馆的两名二十多岁男性，并不是她的男友；公开资料没有披露他们的姓名和职业。

警方与检方调查认为，她把接触到的男性当成消费的承担者，并主动推进约会后的旅馆安排；一审法院认定，主因是经济和消费贪欲，而非爱情纠纷。她“只想让人睡着”“为了防身”的说法，没有被法院采信。

2026年8月27日，一审判处金素英无期徒刑并命令30年电子定位监管；检方曾求处死刑。她于8月28日、检方于9月2日分别上诉，案件仍在二审中。
