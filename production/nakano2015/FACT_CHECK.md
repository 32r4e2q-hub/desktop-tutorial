# 事实核查表｜东京中野女演员尾随案（2015）

- 编制 / 联网复核：2026-11-25
- 核查状态：已通过公开报道交叉核实（产经新闻、每日新闻、日本经济新闻、共同通信、东京体育等；见下方链接）。
- 全片口径：**不展示遗体、伤口、侵害过程与作案细节**；只讲案发、侦查、审判与判决等公开信息。

## 核心事实清单（全片唯一口径）

1. **案发**：2015年8月25日深夜至26日凌晨，东京都中野区弥生町一处公寓，25岁舞台剧演员（剧团成员）加贺谷理沙在住处遇害；26日晚间由同事上门发现。玄关上锁、室内无明显翻动 [1](https://www.sankei.com/article/20150910-JGJZUB25NFO2JBSVMV6YBONF54/) [2](https://friday.kodansha.co.jp/article/439452)。
2. **侦查**：现场遗留的生物痕迹与被害人熟人不符；警视厅采集周边居民、配送人员等约1500人DNA比对，最终锁定案发时住在附近的户仓高広 [3](https://newsee-media.com/tokura-takahiro) [4](https://gobou-chan.com/case/nakano-gekidan/)。
3. **逮捕与供述**：2016年3月12日，户仓高広在福岛县被逮捕（案发后约200天）。他称只是想在返回福岛前与被害人交换联系方式，并称听到“恶魔的声音” [5](https://www.tokyo-sports.co.jp/articles/-/34025)。
4. **一审**：2018年2月至3月，东京地裁裁判员审理。他承认杀害，但否认其他目的，并以精神状态请求减刑。3月7日，法庭以住居侵入、杀人、强制猥亵致死等罪判处**无期徒刑**；法官认定所谓幻听缺乏案发前鉴定支持，责任能力完整 [5](https://www.tokyo-sports.co.jp/articles/-/34025) [6](https://www.nikkei.com/article/DGKKZO27814500X00C18A3CC1000/)。
5. **二审与确定**：2018年12月6日东京高裁驳回上诉、维持无期 [7](https://newspicks.com/news/3513742/)；2019年4月15日最高裁第一小法庭驳回上告，无期徒刑确定 [8](https://www.sankei.com/article/20190416-KMSRAAVETNNFDLCO3SVA4TYSN4/)。
