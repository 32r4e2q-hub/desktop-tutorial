# 迷案解码人｜系列封面工具

用户认可的竖版系列封面：1080×1440，固定背景、栏目、排版和截图框。每期只替换**期数、两行标题、本期视频截图**；截图下方自动显示期数编号。`第一期_西口彰_封面.png` 是第一期示例；`第一期_视频截图示例.jpg` 取自西口彰待审初剪约 134 秒，已裁去字幕，仅作第一期示范，不能用于别期。

仓库的 `NotoSerifCJKsc-Common.otf` 与编辑器内嵌字体同属常用字子集，许可见 `OFL.txt`。`plate.jpg` 是预处理过的固定背景。CLI 和浏览器编辑器可以离线运行，各自渲染会有细微差异，需视觉复核。

## Agent 自动流程

用户只说第几期时，结合当前对话和项目材料识别案件、核实事实，自拟发布标题和封面两行；自动从**本期**已审核的视频选取贴合标题的一帧，并裁掉字幕等多余内容，选择后必须检查缩略图是否保留画面主体。如果只有待审初剪，选帧可以使用但要如实说明。拿不准是哪一案或本期没有视频/可靠截图时先问，绝不沿用第一期示例图冒充。固定文案「真实案件」「动画情景复原」不适用于当前内容时先确认。完整约定见根目录 `AGENTS.md` 和 `新题目开工手册.md`。

首次安装依赖（安装可能需要联网；安装后生成离线运行）：

```bash
python3 -m pip install 'pillow>=10,<13' 'fonttools>=4.50,<5' 'av>=12,<19'
# 或安装完整工具链：python3 -m pip install -r production/requirements.txt
```

以下以第一期事实与待审初剪演示，输出放临时目录，**不是新一期**。数字为源帧像素坐标 `(左, 上, 右, 下)`，取帧和裁剪由 Agent 依据实际视频选择和审核：

```bash
python3 production/mystery-cover-template/generate_cover.py \
  --episode 1 --line1 '逃亡78天的西口彰' --line2 '却被女孩一眼认出' \
  --video '交付/Nishiguchi_First_Cut.mp4' --time 134 --crop 0 64 1920 855 \
  --release-title '逃亡78天的西口彰，却被女孩一眼认出' \
  --fact-basis 'production/nishiguchi1963/screenplay.md 和 qa/review_round5.md' \
  --output work/cover/第一期.png
```

也可将 `--video ... --time ...` 改为 `--screenshot /路径/本期已选截图.png`；可以对截图再用 `--crop LEFT TOP RIGHT BOTTOM`。二者必须提供且只能选其一，程序不会默认使用示例图。截图或裁剪后的区域会**居中裁切**填满固定画框，可能切掉边缘；取帧时间、截图来源及裁剪参数会写入同名 JSON，截图来源由 Agent 核实。CLI 不会自主选帧、拟题或核查事实。

`--episode` 为 1–9999 的整数，输出角标如「第二期」；标题两行各 1–18 个字符，过长报错，较长行自动缩字号。JSON 含期数、两行封面标题、发布标题、事实依据和截图来源；省略 `--release-title` 时以逗号连接两行。默认拒绝覆盖 PNG **或**同名 JSON；明确更新时可用 `--force`。字体缺字时报错，可用 `--font /路径/高覆盖字体.otf` 指定合规 OTF/TTF，并复核外观。

生成后打开 PNG，核对期数、标题、字形、画面来源、裁剪和事实，不能把自动化通过说成人工签收。图片中的动画不是历史影像，封面背景是根据参考氛围重创，不是去除水印后的原图。

## 离线浏览器编辑器

下载模板包并打开 `封面模板_可编辑.html`：输入数字期数和两行标题，选择**本期截图图片**，预览后下载 PNG。页面不自动读取视频，需先从本期视频截帧；更换期数会清空截图，必须重新选择，避免误用上期图片。包里附第一期裁剪截图，只供试用第一期。截图在浏览器本地读取，不上传；不支持自动检查截图事实、字幕或缺字，导出前须人工复核。与 CLI 不同，编辑器遇生僻字可能使用系统字体。
