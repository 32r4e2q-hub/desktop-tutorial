# 史实核对 · 华城连环杀人案（李春才，1986–2020）

**用途**：成片里每一句解说、每一张信息卡、片尾卡上的每个数字，都要能在这份文档里找到出处；
来源互相打架的地方，写明「成片怎么处理」。核对对象是 `build_story.py` 的六段解说与七张信息卡。
编号与 `story.json` 的 `sources` 一一对应。

口径基准：**以警方、法院与主流媒体确认的事实为准**；维基百科（来源 1、10）用来取框架与聚合数字
（动员人次、排查人数、鉴定组数），案件定性一律以 CNN / SCMP / 联合通讯社 / 中新网为准。
受害者姓名**不在成片与本文档里出现**，只用聚合数字（十位女性 / 十三岁到七十一岁）。
中文译名：이춘재 译 **李春才**（亦作李春在、李春宰，维基百科并列）；윤성여 译 **尹成汝**（亦作尹城汝）。

## 四、成片不出现的内容（红线）

- 不出现受害者姓名、面容、遗体与遇害过程描写；
- 不出现作案手法（捆绑方式、凶器）与任何血腥画面；
- 不还原李春才、尹成汝等真实人物的容貌（李春才一九八六至一九九四年情景由虚构匿名角色 C1 扮演，二〇一九年后只给背影）；
- 不出现可读文字、门牌、招牌（视频模型会编字，靠构图排除）；
- 不使用任何真实搜查、审讯、庭审、监控或证物影像。
