# 制作过程 · 《李春才：华城连环杀人案，DNA揭开了33年的秘密》

照 [`新题目开工手册.md`](../../新题目开工手册.md)（狂犬病模式）做的第五部片子，
第四部露脸模式的片子（前三部是《雨夜屠夫林过云》《韩国雨衣杀手柳永哲》《日本座间九人案》）。
用户指定按 **`zama2017-v1`（座间九人案）模板**制作，并提了四条硬要求：
**3D 动画视频（不是图片视频）、人物鲜活（不同人物不同脸、同一人物同一张脸）、
动作幅度大（中景/全景 + 明确动作 + 运动镜头，不要人脸特写糊弄）、内容丰富饱满**。

分支：`arena/6f5577f1-desktop-tutorial`　项目：`production/hwaseong1986`
成片目标：180 秒 / 1920×1080 / 30 fps / 45 镜（38 Agnes + 7 信息卡）。

---

## 1. 选题与素材来源

- 用户上传的 40 镜文案稿（`paste-area/pasted.txt`，经粘贴区保存）给出叙事骨架：
  钩子（真凶在狱）→ 黑暗年代 → 调查歧途 → 真相浮现 → 冤案平反 → 结尾。
- 上传稿的事实按 10 条公开来源逐句核对并改写了三处（见 `史实核对.md` 第三节）：
  DNA 比中的具体案次（第 5/7/9 案）、承认的时间线（10-01 九起、10-04 第十起）、
  平反日期（二〇二〇年十二月十七日水原地方法院）。
- 事实核查来源：中文维基（框架与聚合数字）、CNN（2020-07-03 警方结论与致歉、2020-11-02 法庭认罪、
  2020-12-17 无罪宣判）、SCMP（十四起、追诉时效 2006 年届满、2015 年废除不溯及既往、《杀人回忆》原型）、
  Business Insider 转引联合通讯社（九次入狱会面、约三十起性犯罪）、中新网（水原地方法院宣判、二十年冤狱）、
  Hani 中文（证人身份出庭、其他三起清州/华西站命案）、韩国日报（DNA 法修订）。

## 2. 与上传稿的差异（用户稿 → 成片稿）

| 上传稿 | 成片 | 为什么 |
|---|---|---|
| 40 镜 × 约 4.5 秒 | 45 镜 × 4 秒规划网格（38 Agnes + 7 信息卡） | 本流水线是三分钟 45 镜结构，镜头数变了、内容不变 |
| 片名叫「李春才：华城连环杀人案」 | 片名不变，副题强调「DNA揭开了33年的秘密」 | 保留用户命名；DNA 破案是本片主线 |
| 未提电影《杀人回忆》 | N06 加入「被拍成电影《杀人回忆》，警醒一代人」 | SCMP 证实；抖音观众最熟的钩子之一 |
| 未提调查规模 | N03 加入「两百多万人次 / 两万多名嫌疑人 / 五百七十组DNA」 | 维基聚合数字；信息卡 S19 同源，是全片最有冲击力的数字 |
| 未提尹成汝假释年份 | 只说「坐了二十年牢」 | 各家口径不一（2009 假释 / 2010 出狱），不挑一个当结论 |
| 人物多为环境描写 | 5 个露脸角色、9 个露脸镜头、大量全身/中景动作 | 用户要求「人物鲜活、动作幅度大」 |

## 3. 内容与闸门

```bash
python3 production/hwaseong1986/build_story.py            # 唯一内容源 → story.json + audio/manifest.json
python3 production/face_cast.py check-prompts --project production/hwaseong1986   # 露脸静态闸门
python3 production/hwaseong1986/generate.py --validate    # 闸门一
python3 production/hwaseong1986/clause_times.py --check-cuts   # 切点闸门
```

- 45 镜 = 38 agnes + 7 信息卡（S02 案件名片 / S11 案件开端 / S19 调查规模 / S26 李春才档案 /
  S33 平反 / S39 三十三年 / S41 追诉时效）；每个镜头只用一次，`make_edl` 有断言。
- 解说 6 段 **794 字**（含标点）；TTS 原始 172.42 s → `tighten_pauses.py` 收紧到 162.38 s（只剪静音），
  可用窗口 168 s，整体变速 **0.9666**。
- `CUTS` 用动态规划从分句停顿里选切点（段长下限 2.0 s、末镜 ≤ 8.9 s 胶片时间），
  全部切点落在 [分句起点−0.35 s, 分句起点] 窗内。
- 片尾卡第一行「你能想象吗？」6 个全角字，片头卡两行分别为 7 / 18 字，排字闸门实测不越界。

## 4. 露脸模式（本片重点）

- 五个虚构匿名角色：**C1 年轻男子（李春才 · 一九八六至一九九四年情景）**、**C2 年轻男子（尹成汝 · 一九八八年）**、
  **C3 老刑警（调查本部长）**、**C4 重查组警官（二〇一九年）**、**C5 女法医（DNA 检测）**。
  `cast.json` 里每人一条面容 token（≥60 字）、一个固定 seed、一张定妆照。
  **不做任何真实人物的肖像还原**——李春才在二〇一九年后的镜头只给背影。
- 同一张脸跨镜稳定靠三件事叠加（与座间/林过云同一套接线，`generate.py` 的 `cast_ledger` /
  `shot_seed` 从座间版逐字移植）：
  1. 提示词里**逐字节**照抄该角色的 face token（`{C1}`…`{C5}` 占位符从 `cast.json` 注入）；
  2. 单角色镜头用**角色 seed**（C1=19860915 首案日 / C2=19880916 第八案日 / C3=19861212 /
     C4=20190919 DNA 突破日 / C5=20190801 比对月）；
  3. 五个角色的**首次露脸镜头（S06 / S12 / S16 / S27 / S40）用定妆照做图生视频首帧**。
- 动作幅度：`STYLE_PREFIX` 明确要求 `full-body movement and expressive gesture, staged in medium
  and wide shots rather than close-ups`；分镜里 9 个露脸镜头有 6 个是全身/中景动作镜
  （夜路行走、地图墙撑墙、公交站被拦、法庭被告席、审讯低头、讲台发言），
  只有 S06 / S27 / S40 是偏近的镜位，且都有明确动作（望窗、对报告、举证物）。

## 5. 引擎改动（相对脚手架的增量，均有出处）

| 文件 | 改动 | 出处 |
|---|---|---|
| `generate.py` | 移植 `cast_ledger()` / `shot_seed()` / `reference_image` 图生视频接线 | 座间九人案 `generate.py` 逐字移植 |
| `render.py` | 移植 `DEFAULT_GRADE` / `GRADE_OVERRIDES`（夜景镜头单独调色钩子） | 林过云/座间的解法 |

## 6. 踩到与解决的问题

| 问题 | 处理 |
|---|---|
| 沙箱无 ffmpeg / ffprobe / numpy / pillow | `pip install numpy pillow pytest pyyaml av` + imageio-ffmpeg 的静态 ffmpeg 放进 `~/.local/bin` |
| `media.py::probe` 走 PyAV 回退被假 ffprobe 挡着 | 删掉自建的 ffprobe 符号链接（probe 本来就有 PyAV 分支） |
| 排字闸门因无中文字体**静默跳过**（手册警告过的坑） | 从 PyPI 的 mplfonts  wheel 里取出 Noto Sans/Serif CJK SC 两个 OTF 放进 `.cache/fonts/`（`.cache/` 不入 Git），闸门真跑并通过 |
| 解说初稿 687 字偏少（168 s 窗口会剩 ~28 s 静默） | 按用户「内容丰富饱满」的要求充实到 794 字，每章加一条有出处的事实或氛围句 |
| 编辑 build_story.py 时把 `\n` 写进了 N01 解说词 | 发现后删除并重跑 build/clause_times/validate（三处逐字一致由闸门守着） |
| CUTS 自动对轨首版有 1.6 s 碎段、N03 无可行解 | 改为动态规划选边界（最小化段长方差），段长下限 2.0 s；N03 首段 2.13 s 因此放行 |
| `new_topic.py` 补丁插重导致 generate.py 出现重复函数 | 从参考实现恢复后重新精确打补丁，语法闸门 + 冒烟测试验证 |

## 7. 本地冒烟测试（手册第 8 步，出片前必做）

用 `testsrc2` 造 38 个 7 秒假素材 + 按 `request_hash` / SHA-256 写 `results.json`，
`render.py --skip-asr --width 960 --height 540` 全流程跑通：
**46 段 / 180.0 s / 5400 帧 / 38 素材 / tempo 0.9666 / RMS −20.63 dBFS / 峰值 −1.45 dBFS / 静音 1.1 %**。
CUTS、露脸接线、`GRADE_OVERRIDES` 补丁全部验证无误后才提的 `GEN_REQUEST`。
