# 本地预演（不碰 Actions，用真实旁白 + 占位音轨）

沙箱没有源片（在 Actions 的 `work/holmes1893/sources`），所以这里只预演**音频 + 字幕 + 片尾卡**：

1. `build_audio.build_soundtrack()` 跑通：180.0 s / 48 kHz 立体声，
   RMS −21.4 dBFS、峰值 −1.5 dBFS、静音窗口占比 1.1%、旁白下压配乐 −18.7 dB（目标 −18 dB）。
   四个缺录音的镜头用同长低电平正弦占位，仅本地 `/tmp`，不进仓库。
2. `render.write_subtitles()` 生成 ASS：30 条字幕 + 双层画面角标 + 27 个圆点 + 片尾卡，libass 无报错。
3. 抽帧目检：字幕为白色描边 + 金色关键词，落在下三分之一安全区；片尾卡 200 / 9 与问句层次清楚。

## 本轮修掉的两个真问题
1. **右上角「AI动画情景复原 · 非真实影像」被切掉**：原来是 `\pos(1824,42)` + 默认 `\an2` 居中对齐，
   一段 24 号字以 1824 为中心向右超出 1920 画幅，只露出半截。改为 `\an9\pos(1868,42)`（右上对齐），
   与左边角标（默认左上角，MarginL 96）左右对称。
2. **沙箱重建后中文字幕全变方框**：`~/.local` 与 `.cache` 不进快照，`ffmpeg` 与 Noto CJK 字体都会丢。
   新增 `production/holmes1893/dev_bootstrap.sh`：装 numpy / imageio-ffmpeg / pillow、软链 ffmpeg、
   生成 ffprobe shim、从名为 `mplfonts` 的 PyPI 包（0.0.11，自带 Noto CJK OTF）解出两款字体。
   另外 libass 需要 fontconfig 认识字体：把 `FONTCONFIG_FILE` 指向只含 `.cache/fonts` 的配置即可，
   否则即使 `fontsdir` 加载了字体，family 名仍解析失败。
