## 制作与验收流程

1. 口播、分镜与来源先审查；六段TTS经停顿处理后重新校验文本、时长及SHA-256。
2. `clause_times.py --check-cuts` 检查镜头切点；渲染字幕使用分句时间，能用ASR时再逐章对轨。
3. `generate.py --validate` 检查180秒计划、45镜构成、口播与配音哈希。
4. 通过 `GEN_REQUEST` 触发 Agnes；按提示词哈希复用未改变的素材，只重做修改镜头。检查每镜接触表和结果回执。
5. 人工逐镜记录叙事匹配、畸变/手部、伪文字、镜头中途变化、运镜及标签；问题镜修复后再次检查。
6. 通过 `RENDER_REQUEST` 出片；复核画幅、帧率、时长、黑帧/冻结帧、字幕切点、声音响度/峰值/静音和音画同步。
7. 通过 `VERBATIM_REQUEST` 做逐章逐字听检（每章CER ≤ 0.15）。报告未通过或人工画面复核未完成时，不签收。

云端生成按 Agnes 官方速率执行，不绕过限流。工作流模板保留在 `workflows/`，本分支的 `.github/workflows/btk-*.yml` 已安装。
