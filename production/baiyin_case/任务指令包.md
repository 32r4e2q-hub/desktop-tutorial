## 六、电影感专项规范（本版重点 · 强制执行）

### 6.1 镜头语言（Camera）
- **浅景深为默认**：大光圈 f/1.4–f/2.8，主体锐利、背景奶油化虚化（bokeh）。仅信息展示镜头（镜06、22、27）用小光圈保留清晰度。
- **运镜方式**：
  - 轨道/稳定器缓推缓拉为主，禁止无意义乱晃
  - 手持微晃仅用于镜12、14、20、23，制造纪实质感与不安
  - 斯坦尼康长跟拍用于镜17、24
  - **希区柯克变焦（dolly zoom）**用于镜25，是情绪冲击的核心技巧
- **升格慢动作**：镜05、17、25 用 60/120fps 拍摄降格至 24fps，关键瞬间"时间被拉长"
- **固定镜头也要"活"**：所有固定镜头加极缓慢的推进（每秒数像素），杜绝死板静帧

### 6.2 光影（Lighting）
- **低调照明（low-key）为主基调**：大面积暗部 + 小面积高光，营造悬疑压抑
- **伦勃朗光**：所有人物特写（镜02、14、21）用 45° 侧光，脸颊形成三角光斑
- **侧逆光/剪影**：镜08 用轮廓光勾勒人形，不发细节
- **丁达尔效应（体积光）**：镜07、09 让窗光穿透浮尘形成可见光柱
- **实用光源（practical light）**：手机屏、台灯、霓虹、红灯笼作为画面内光源，增强真实感
- **屏幕光打脸**：所有数据库/比对屏幕相关镜头（镜20、22）用屏幕冷光照亮局部；人物一律背影/剪影，不打正脸

### 6.3 调色（Color Grading）
- **主色调：青橙对比（Teal & Orange）**——暗部压向青蓝（夜景、档案室、实验室、现实追凶段），亮部推向暖橙（日常伪装段：镜13/14/15、1988回忆）
- **暖色/日常伪装段（镜04、13、14、15）**：暖黄、过曝、褪色、颗粒加重（"记忆与伪装的暖色滤镜"，刻意制造反衬）
- **现实段**：低饱和、冷青、压暗黑位（crushed blacks）
- **胶片 LUT**：Kodak Vision3 250D / Fuji Eterna 风格；胶片颗粒 15–25；高光柔化（halation）；轻微暗角（vignette）
- **色彩叙事**：暖→冷的关键转折在镜05完成，此后冷调主导直到结尾

### 6.4 构图（Composition）
- 三分法为基线；镜26 用中心对称构图体现法庭庄严
- 框架构图（门框/窗框/树枝）：镜07、24
- 前景遮挡增加纵深层次：镜07、09
- 负空间/留白：镜01、09、29
- 分屏对比：镜18（冷vs暖）、镜22（旧vs新）

### 6.5 质感细节（Texture）
- **变形宽银幕镜头光晕**（anamorphic flare，蓝色横条光斑）：镜01、03、17
- 椭圆焦外散景（anamorphic bokeh）
- 运动模糊：快门角度保持 180°
- 浮尘/粒子、霜花微距、纸张纤维等微观质感镜头穿插

### 6.6 声音（Sound Design，电影感混音）
- **动态范围要大**：安静处极安静，冲击点音量拉满，避免全程一个音量
- **360° 环境声场**：不只是 BGM，要有脚步、开门、压缩机、打字、钟声等具体环境音
- **次声（sub-bass）**：低频压迫感贯穿悬疑段
- **声音桥接（J-cut / sound bridge）**：声音先于画面进入，转场更顺滑
- 镜18、镜25 的"声音全收"是情绪引爆点，必须保留

### 6.7 转场（Transitions）
- 以**硬切（hard cut）**为主，禁用花哨综艺转场
- **匹配剪辑**：形状/动作/视线相似处剪切（镜04、28）
- **色彩渐变转场**：镜05 暖→冷
- **声音先入**：重要段落声音提前半拍

## 七、全局制作规范

**解说/配音**：
- 语速比日常快 10%–15%；钩子段（镜01–02）要慢、有压迫感
- 选有情绪起伏的 AI 音色，不要机械平读
- "28年"全片至少出现5次（镜01画面字幕、镜02台词、镜12台词+字幕、镜17/18/25/29/30台词），这是记忆锚点，不得删减

**画面**：
- 所有真实姓名、身份证、判决书信息必须打码或模糊
- 绝不出现血腥画面：镜08用剪影、镜25用切黑，比直接展示更过审、更高级
- 镜头平均切换频率 2–4 秒，无拖沓

**音乐/音效**：
- 低频氛围音打底，关键处留白静音再做音效冲击
- 镜18、镜25 的"声音全收"是全片情绪引爆点，必须保留

**字幕**：
- 全片必须配字幕（适配静音刷视频用户）
- 关键词变色/放大（红字为主）
- 字幕排版遵循电影字幕风格：细体、字距舒适、安全区内、避免遮挡主体

## 八、节奏自检曲线

- 0–6s：钩子必须炸，前2秒无解说只有音效与光晕动画
- 6–50s：铺垫+案发，"慢—快—停"，镜08/09刻意留白；镜05完成暖→冷色彩转折
- 50–95s：伪装段是核心，镜18分屏对比推到第一情绪高点
- 95–135s：破绽段持续加速，镜25（希区柯克变焦+升格+切黑）是全片引爆点
- 135–180s：冷静收束，金句+互动引导，把看客转化为评论者；镜30呼应镜02形成闭环

## 九、数据验收标准

- 3秒完播率 > 70%
- 整体完播率 > 30%
- 平均播放时长 > 60秒
- 互动率（评论+点赞）> 3%

## 十二、实测反面案例诊断与规避清单（重要 · 必读）

> 本节来自对一条真实成片（3分钟横版案件解说，AI生成画面）的逐帧诊断。**以下每一条都是已实际发生的问题**，执行时必须逐项规避。自检时把本节当作"负面清单"逐条打勾确认"未发生"。

### 12.1 画质与格式（硬性红线）

| 实测问题 | 后果 | 规避做法 |
|---|---|---|
| 成片仅 568×320、0.8Mbps | 全片发糊、廉价感、3秒跳出率飙升 | 最低 1080P 交付，码率 ≥15Mbps；素材源 ≤720p 时须经免费AI超分（16.1.2）放大到1080P，禁止直接放大不使用超分 |

### 12.2 开头钩子（决定跳出率）

**反面案例**：前3秒用静态UI界面/波形/纯文字 + 绕口设问（"XX秒前，你……"）。

- ❌ **禁止用静态UI界面/波形/纯文字做开头钩子**——这不是"画面"，没有视觉冲击，观众无代入
- ❌ 禁止用"XX秒前，你……"这类绕弯的第二人称设问——信息传达慢，3秒内说不清核心冲突
- ✅ **必须**在前3秒给出：一个反常事实 + 一张强视觉画面（人物冲突/物证特写/反常现象），让观众一眼知道"出事了"
- ⚠️ 若要用某一视觉符号（如手机界面、波形等）做全片线索，只能作为**点缀穿插**（≤2次、每次≤2秒），不得占据开头或结尾的黄金位

### 12.3 画面真实感（决定信任度）—— 去AI味/去偶像剧味完整执行方案

**反面案例**：清一色偶像剧脸 + 花田自拍、夕阳看海、温室等"唯美空镜"，观众当成MV。

#### 12.3.1 病根诊断（为什么会"AI味/偶像剧味"）

| 病根 | 表现 | 观众感受 |
|---|---|---|
| 脸太精致 | AI默认出对称五官、磨皮、网红脸 | "这是演员在演，不是真人真事" |
| 景太唯美 | 花田、夕阳、海边、温室、慢镜头飘发 | "这是MV/婚纱照，跟命案有什么关系" |
| 光太干净 | 无噪点、无脏污、构图完美、色彩通透 | "太假了，一看就是生成的" |

**核心原则：真实感来自"不完美"。案件解说的画面要像新闻纪实/监控录像，不像广告片。**

#### 12.3.2 镜头替换对照表（硬性执行）

| ❌ 禁用（偶像剧/AI味） | ✅ 替换为（纪实质感） |
|---|---|
| 花田自拍、笑脸特写 | 手机屏幕里的照片（带边框、反光、手指） |
| 夕阳看海唯美剪影 | 楼道/小区监控视角（CCTV，带时间码、轻微畸变） |
| 精致正脸大特写 | 背影、侧脸、局部（手/脚/肩膀）、剪影 |
| 干净明亮的室内摆拍 | 有杂物、有阴影、局部过曝或欠曝的真实环境 |
| 慢镜头回眸、飘发 | 固定机位的呆滞瞬间、无表情静止 |
| 两人并肩唯美漫步 | 两人隔着距离的背影，或只有一人的空镜 |

#### 12.3.4 后期"降质感"参数（直接抄）

| 参数 | 设置 | 目的 |
|---|---|---|
| 胶片颗粒 grain | 15–25 | 打破数字生成的"塑料感" |

#### 12.3.5 素材来源优先级（从高到低）

1. **真实新闻素材 / 公开监控 / 裁判文书截图**（最高可信度）
2. **纪实风格AI生成**（监控视角、背影、局部特写）
3. **新闻截图二次加工**（打码、裁切、加新闻字幕条）

- ✅ 关键情绪用**物的特写**代替**脸的特写**：血滴、指纹卡、卷宗、小卖部柜台、手铐、族谱、判决书

- 出现 ≥3 张精致正脸 → ❌ 不合格
- 出现花田 / 夕阳 / 海边自拍 → ❌ 不合格
- 没有任何物证 / 界面 / 手部 / 监控视角镜头 → ❌ 不合格

### 12.4 节奏结构（决定完播率）

**反面案例**：同一个静态元素（如波形/界面/定格）出现3次（开头/中段/结尾）共占约14秒；中段10–50s连铺4个低效画面；结尾6秒只有定格+标题。

**反面案例**：只有"统一冷蓝色调"，无光影层次、无景深、无运镜、无升格——是"滤镜"不是"电影感"。

  - **暖冷色彩对立**——回忆段暖、现实段冷，转折明确（如镜05）

- ✅ 自检方法：抽看任意10帧，若超过7帧"构图雷同、明暗均匀、无焦点"，则电影感不达标

### 12.6 字幕（决定信息传达）

- ❌ 禁止双行以上字幕（一行不超过16字，超长拆成上下镜头）

## 十四、角色一致性工作流：参考图驱动的视频生成（强制执行）

> 本节解决"同一人物在不同镜头里长相不一致"的问题。**禁止每镜独立随机生成人物**——那样会导致主角在30镜里换30张脸，观众瞬间出戏。必须走"先定妆、后生视频"的两阶段工作流。

### 14.1 核心原理

```
阶段A：文生图 → 批量生成两类参考图，全部事先生成好：
        ① 角色三视图定妆照（正面/侧面/背面）—— 锁定人物长相
        ② 场景参考图（西北小城/现场空镜/档案室/小卖部/族谱/实验室/法庭等）—— 锁定场景外观与色调
阶段B：图生视频 → 把"人物图 + 场景图"一起作为参考图/首帧喂给视频生成工具，
        配合运镜提示词生成每个视频片段
```

**为什么必须这样做**：
- **人物**：AI视频每次生成都是随机的，光靠文字描述无法保证人物一致；只有把**同一张人物参考图**反复喂进去，才能锁定五官、发型、衣着。
- **场景**：同理，同一地点在不同镜头里必须长得一样（同一个小卖部、同一个档案室、同一个族谱界面），否则观众会察觉场景跳变。事先生成场景图并复用，还能**统一全片色调**（日常伪装暖、追凶现实冷），这是电影感的基础。

> ⚠️ 关键：所有参考图（人物+场景）必须在**任何视频生成开始之前**全部生成完毕并归档。**禁止边生视频边补参考图**——那会导致前后镜头风格断裂。

### 14.2 阶段A：生成参考图库（文生图）—— 人物 + 场景

**第一步：为每个主要角色建立"角色档案卡"**

| 高承勇（嫌疑人·仅背影/剪影呈现） | 约52岁 | **默认锚点**：黑色短发、偏瘦、中等脸型、微驼；**只用背影/侧影/剪影，禁止清晰正脸与真实长相还原**（直接采用） | 深色夹克+围裙（小卖部经营者） | 沉默、温和的伪装感 |

### 14.3 阶段B：参考图 → 图生视频

**工作流（人物图 + 场景图 双参考）**：
1. 从参考图库选出该镜需要的**人物视角图**（如"高承勇背影镜头"→ `承勇_back.png`）
2. 再选出该镜的**场景参考图**（如"小卖部"→ `LOC07_小卖部.png`；"血滴"→ `LOC04_血滴微距.png`）
3. 将两张（或多张）参考图**一起上传**给视频生成工具作为条件：
   - 若工具支持"多图参考/角色参考+场景参考"双通道（如即梦、可灵、Vidu 等）：人物图放角色参考位，场景图放背景/首帧位
   - 若工具只支持单张首帧：先用**文生图把人物图与场景图合成一张"该镜首帧"**，再把这张合成图作为首帧喂给图生视频
4. 配合运镜提示词生成视频片段

**合成首帧法（工具只认单图时的标准做法）**：
```
人物参考图 + 场景参考图 → 文生图合成 → 该镜首帧图 → 图生视频
例：承勇_back.png + LOC07_小卖部.png
   → 合成"高承勇背影站在小卖部柜台后"的首帧
   → 图生视频（缓慢推近 + 纪实质感）
```
> 这样每张首帧都同时锁定了"这个人"和"这个场景"，生成结果稳定可控。

**图生视频提示词模板**：
```
[人物参考图中的角色] + [场景参考图中的环境] + [该镜画面内容] + [运镜方式] 
+ documentary style, film grain, handheld slight shake, 
  natural motion, muted cold color, consistent character, consistent location
--negative: face morphing, identity change, scene change, extra limbs, 
  distorted hands, smooth plastic skin, slow motion beauty shot
```

**运镜提示词库**（从第六节映射）：
| 运镜需求 | 英文提示词 |
|---|---|
| 缓慢推近 | slow push in, camera slowly dolly forward |
| 缓慢拉远 | slow pull back, camera dolly out |
| 平移跟拍 | tracking shot, camera pan follow |
| 手持微晃 | handheld, slight camera shake |
| 固定镜头微动 | static shot with subtle motion |
| 升格慢动作 | slow motion, high frame rate |

**关键参数**：
- 每段生成时长：5–10秒（够一个镜头用，太长易崩）
- 一致性强度：调高（若工具支持"角色一致性/参考强度"参数）
- 运动幅度：低到中（幅度越大越容易把人脸生成崩）

### 14.6 与"去AI味"规范的衔接（重要）

本节的角色一致性工作流**必须服从 12.3 节的去AI味要求**：

- 参考图本身就要按 12.3.3 的"纪实风格正向词 + 负面词"生成——**不要生成精致偶像脸的定妆照**，否则一致性做得再好，也是"同一张偶像脸贯穿全片"，观众照样出戏
- 人物呈现继续遵守 12.3.6：优先用**背影/侧脸/局部**，正脸大特写全片不超过3次
- 即使有定妆照，也**不等于要在片里展示正脸**——参考图是给AI看的"锚"，不是给观众看的"脸"
- 图生视频后统一做 12.3.4 的降质感处理（颗粒/降锐化/色偏），把AI的"塑料感"压下去

> 💡 一句话总结：**参考图负责"像同一个人"，纪实风格负责"像真的事"——两者缺一不可。**

2. **风格对齐**：换工具产出的画面，统一套 6.3 的同一 LUT + 颗粒参数；音频统一归一到 −14dB、同一音色 ID，避免"换工具=换风格"。
3. **留痕**：每次切换在 `QC报告.md` 记录"某镜 从工具A→工具B，原因=___"，便于复盘，**但绝不因记录而中断出片**。

### 16.7 遇到问题，直接解决（全自动硬性原则 · 不许提问）

> **这是全片的总原则：接收方 Agent 遇到任何问题，第一反应是"自己解决"，不是"问用户"。** 除非遇到"完全无任何生成工具"这一物理限制（见开头可行性声明），否则一律自主处置、全程不问人。文档已经把所有决策定死，你没有需要询问用户的理由。

**问题—动作对照表（遇到问题照做，不用想、不用问）**：

| 遇到的问题 | 立即执行的动作（不问人） |
|---|---|
| 某工具报错 / 崩溃 / 连不上 | 重试1次 → 按16.6换下一款工具 → 继续，不中断 |
| 工具限流 / 排队太久 / 额度用完 | 换免费或国内备用工具 → 错峰重试 → 降级方案 |
| 生成的脸崩 / 多指 / 身体畸变 | 换seed重试2–3次 → 重喂 `_front.png` 强化 → 改背影/剪影机位 → 静帧+运镜 |
| 场景/人物前后不一致 | 重新加载对应参考图，一致性强度调高 → 仍不符则改用不依赖该角色的机位（物证/空镜/背影） |
| 画面黑帧 / 冻结帧 / 花屏 | 按18.1检测定位 → 该镜重生成（≤3次）→ 降级静帧+运镜 |
| 色调不统一 / 忽冷忽暖 | 全片统一套用6.3的青橙LUT+颗粒参数重导出；回忆暖、现实冷按第5节逐镜校正 |
| 配音时长与画面不符 | 语速±10%微调；仍不符则画面时长±0.5s微调，**音画同步优先** |
| 音色被判缺失 / 情绪不对 | 按16.2换最接近沉稳男声，全片统一同一音色ID重录；情绪按13.1逐镜提示 |
| 字幕乱码 / 被遮 / 串行 | 换中文字体（思源黑体/苹方）→ 用ASS显式定位到安全区 → 对照13.1逐句校正 |
| 音画不同步 | 按18.1⑦检查音视频流起点 → FFmpeg 对齐偏移 → 重导 |
| 版权拿不准 | 一律换成明确可商用来源或AI原创；宁可少用一个音效，不冒侵权限流风险 |
| 不懂某个术语 | 查第十九节术语速查表 + 第5节该镜"电影感处理"列 |
| 没有视觉能力做抽帧检验 | 用自动化检测（黑帧/冻结帧/模糊度/色彩统计）替代目视，记录后继续，不标"待人工确认" |
| 某个环节怎么都过不了 QC | 按18.2.3判定走 DEGRADE（降级）或 REVIEW（按第十节合规处理）；**记录降级项后放行该镜，不让单镜拖垮全片** |
| 事实/台词拿不准 | 一律照抄第3节事实线与13.1定稿表，不联网、不改写、不自行添加 |

**自我对话准则（写进 Agent 行为）**：
> 当我想问"这一步该怎么办 / 要不要继续 / 用哪个工具 / 这样行不行"时——**答案是：查文档对应章节 → 选清单里下一个工具 → 按降级规则处理 → 记录在 QC 报告 → 继续往下跑。** 不问用户，不等待确认，直到成片交付。

## 十八、质量检验体系 QA/QC（成片完美交付的最后防线 · 强制执行）

> **核心原则：生成 ≠ 完成，没有经过 QC 的片段和成片一律不得交付。** AI 生成视频天然存在脸崩、畸变、黑帧、音画错位等随机缺陷，只有系统性检验才能拦住。本节把检验分为两层：**片段级 QC（Step 4Q，每段生成后立刻检）** 与 **成片级 QC（Step 6Q，合成后终检）**。
>
> **QA（Quality Assurance，质量保证）** = 管过程：按规范生产、每步留痕；**QC（Quality Control，质量控制）** = 管结果：用数据+肉眼把不合格品挑出来。两者都要做。

### 18.0 检验工具准备

- 首选：FFmpeg/FFprobe（命令行，可脚本化、可复现）+ 抽帧拼图脚本
- 视觉检验：接收方 Agent 用看图能力逐帧审；**无视觉能力时用自动化检测替代**（黑帧/冻结帧/模糊度/色彩统计脚本 + 抽帧存档），**在自检报告记录"已用自动化检测替代目视"**，不得标"待人工确认"阻塞流程
- 所有检验结果写入 `QC报告.md`，**每一项都要有"通过/不通过 + 证据"记录**

---

### 18.1 通用量化检测命令（可直接执行）

```bash
# ① 技术参数体检（分辨率/帧率/码率/时长/编码）
ffprobe -v error -show_entries stream=index,codec_name,codec_type,width,height,r_frame_rate,bit_rate -show_entries format=duration,bit_rate,size -of json Sxx.mp4

# ② 黑帧检测（揪出生成失败的纯黑片段；正常片段不应有大段黑）
ffmpeg -i Sxx.mp4 -vf "blackdetect=d=0.2:pix_th=0.10" -an -f null - 2>&1 | grep black_start

# ③ 冻结帧/卡帧检测（画面卡住不动=生成失败）
ffmpeg -i Sxx.mp4 -vf "freezedetect=n=-60dB:d=0.5" -an -f null - 2>&1 | grep freeze_start

# ④ 音量与爆音检测（配音/成片）
ffmpeg -i audio.wav -af volumedetect -f null - 2>&1 | grep -E "mean_volume|max_volume"

# ⑤ 抽帧（片段：首/中/尾各1帧）
ffmpeg -i Sxx.mp4 -vf "select='eq(n\,0)+eq(n\,FLOOR(n_frames/2))+eq(n\,n_frames-1)'" -vsync 0 qc_%02d.jpg

# ⑥ 抽帧墙（成片：每3秒1帧，拼成缩略图一眼看全片）
ffmpeg -i 成片.mp4 -vf "fps=1/3,scale=320:-1,tile=6x10" -frames:v 1 qc_contact_sheet.jpg

# ⑦ 音画同步检查（对比音视频流起点是否一致）
ffprobe -v error -show_entries stream=index,codec_type,start_time -of csv Sxx.mp4
```

> 阈值参考：分辨率 ≥1920×1080；帧率 24fps；成片码率 ≥15Mbps；音量均值 ≈ −14dB、峰值 ≤ −3dB；单帧黑帧 ≤0.5s（镜25设计性1秒黑屏除外）。

### 18.2 片段级 QC（Step 4Q · 每生成一段立刻检，30段逐一过）

**每一个视频片段 `Sxx.mp4` 生成后立即执行以下三类检验，全部通过才进入下一段。**

#### 18.2.1 自动化技术检测（机器先筛）

```
[ ] ffprobe 参数达标：≥1080P / 24fps / 无异常编码
[ ] 时长达标：5–10s，且与该镜时间码匹配（±0.5s）
[ ] 无黑帧：blackdetect 无 >0.5s 黑段（镜25除外）
[ ] 无冻结帧：freezedetect 无异常卡帧
[ ] 画面非全黑/全白/纯色：抽帧非单调
```

#### 18.2.2 抽帧视觉检验（肉眼/视觉模型逐帧审）

对该段抽 **首/中/尾3帧**，逐帧检查：

```
【畸变与崩坏】—— 最高优先级
[ ] 人脸无畸形：五官端正、无多眼/歪嘴/融化/错位的脸
[ ] 手部正常：无多指/少指/扭曲/粘连的手
[ ] 身体结构正常：无多余肢体、无身体穿模、无比例失调
[ ] 物体无畸变：血滴/试管/指纹卡/门/族谱 无扭曲变形、无糊成一团
[ ] 文字正常：画面内若有文字（日期/数字/字幕），无乱码、无错别字、无糊字

【一致性】—— 对照参考图
[ ] 人物一致：该角色五官/发型/衣着与 _front/_side/_back 参考图一致，未换脸
[ ] 场景一致：背景与 LOCxx 场景参考图一致，同一地点未变样
[ ] 色调正确：暖段（回忆）偏暖、冷段（现实）偏冷，符合第五节该镜设定

【内容与安全】
[ ] 无血腥、无暴力特写（符合镜08剪影、镜25切黑的克制要求）
[ ] 无敏感符号、无误导性真实影像感（AI画面不冒充真实监控）
[ ] 画面serves叙事：能看出该镜在表达什么，不是无意义空镜
```

#### 18.2.3 判定与处置（不合格不硬扛）

| 判定 | 触发条件 | 处置动作 |
|---|---|---|
| ✅ **PASS** | 全部检验通过 | 归档该片段，进入下一段 |
| ⚠️ **RETRY** | 轻微畸变/色调偏差/短黑帧 | 换随机种子、微调提示词重生成，**最多3次** |
| 🔁 **DEGRADE** | 3次仍脸崩/畸变，或该镜本就是背影镜头 | 降级为"高质量静帧 + 运镜动画（推拉/横移）"，保时间线不断 |
| ❌ **REVIEW** | 疑似敏感/合规风险 | 暂停该段，按第十节合规红线处理后再定 |

> **效率提示**：本片以背影/侧脸/局部/物证镜头为主（见12.3.6），人物正脸大特写极少，因此脸崩风险与降级成本都低——这正是去AI味规范的额外好处。

#### 18.2.4 片段QC产出

- `qc/clip_QC记录.md`：30段逐段打勾表（技术+视觉+判定）
- `qc/frames/`：每段3帧存档，便于回溯
- 任一 FAIL 未解决 → **禁止进入 Step 5**

## 十九、术语速查表（新人 Agent 必读 · 防止理解偏差）

> 本指令包含大量影视/剪辑专业术语。为避免新人 Agent 望文生义导致执行走样，此处给出**大白话解释 + 本片具体用法**。老手可跳过。

### 19.1 摄影/运镜术语

| 术语 | 大白话 | 本片用在哪 |
|---|---|---|
| **景别**（大特写/近景/中景/远景） | 拍多近：大特写=只拍局部（一只手、霜花），远景=拍全景（城市、楼栋） | 见第五节每镜"景别·运镜"列 |
| **推/拉（dolly in/out）** | 镜头慢慢靠近/远离主体 | 镜21父亲特写缓慢推近 |
| **斯坦尼康跟拍** | 摄影机稳稳跟着人物走，画面不晃 | 镜17、镜24 |
| **手持微晃** | 故意轻微抖动，制造"真实纪实"感 | 镜12、14、20、23 |
| **希区柯克变焦（dolly zoom）** | 镜头往后拉、同时变焦推近，背景空间被"拉伸扭曲"，制造眩晕惊恐 | 镜25（全片高潮） |
| **升格/降格** | 升格=高速拍摄（120fps）后放慢播放，动作变慢；降格反之 | 镜05、17、25 用 60/120fps |
| **浅景深 / f值** | 主体清晰、背景模糊；f值越小越糊（f/1.4 超糊，f/8 都清楚） | 默认 f/1.4–2.8；信息镜06/22/27 用小光圈保清晰 |
| **180°快门** | 快门速度=帧率×2（24fps→1/48s），运动模糊最自然 | 全局默认 |
| **变形镜头光晕（anamorphic flare）** | 横向拉长的蓝色条状光斑，电影高级感标志 | 镜01、03、17 |

### 19.2 光影/色彩术语

| 术语 | 大白话 | 本片用在哪 |
|---|---|---|
| **低调照明（low-key）** | 大面积暗、小面积亮，压抑悬疑 | 全片主基调 |
| **伦勃朗光** | 45°侧光，脸颊上留一个三角形亮斑，肖像画那种立体感 | 镜02、14、21 |
| **侧逆光/剪影** | 光从背后打，人物只剩黑色轮廓，看不清细节 | 镜08（避免血腥） |
| **丁达尔效应/体积光** | 光穿过灰尘/雾，能看到一道道光柱 | 镜07、09 |
| **实用光源（practical light）** | 画面里真实存在的光源（手机屏、台灯、霓虹、红灯笼）来照明 | 手机/台灯/霓虹镜 |
| **青橙调色（Teal & Orange）** | 暗部偏青蓝、亮部偏暖橙，电影最经典配色 | 全片；暖=回忆，冷=现实 |

| **颗粒/暗角（grain/vignette）** | 加胶片噪点 + 四角压暗，去数字塑料感 | 颗粒15–25，轻微暗角 |
| **crushed blacks** | 把黑色压得更黑、更沉 | 现实段 |

### 19.3 剪辑/声音术语

| 术语 | 大白话 | 本片用在哪 |
|---|---|---|
| **硬切（hard cut）** | 镜头直接切换，不加花哨转场 | 全局默认，禁综艺转场 |
| **匹配剪辑** | 形状/动作相似处剪切（笑脸接笑脸），转场顺滑 | 镜04、28 |
| **J-cut / 声音桥接** | 声音先于画面进入（先听到声音，下一镜才看到画面） | 段落转场 |
| **次声（sub-bass）** | 超低频（人耳勉强听到），制造胸口发闷的压迫感 | 悬疑段铺底 |
| **声音全收** | 把BGM和环境音全部抽走，留绝对静音，制造冲击 | 镜18、镜25 |
| **动态范围** | 最安静和最响的差距要大，别全程一个音量 | 全局；安静处极静、冲击点拉满 |
| **dB / dBFS / LUFS** | 音量单位。均值≈−14dB、峰值≤−3dB 是本片标准（见9/12节） | 配音与成片电平 |
| **黑场/留白** | 纯黑画面或静止，给观众情绪消化时间 | 镜25切黑1秒、镜29金句 |

### 19.4 生成/制作术语

| 术语 | 大白话 | 本片用在哪 |
|---|---|---|
| **文生图 / 图生视频** | 文字生成图片 / 用图片生成会动的视频 | 第十四节参考图→片段 |
| **参考图/首帧** | 给AI看的"锚"，锁定人物长相或场景外观 | 三视图、场景空镜 |
| **一致性/参考强度** | 让AI生成时严格贴合参考图，别换脸换场景 | 图生视频参数调高 |
| **负面提示词（negative prompt）** | 告诉AI"不要生成什么"（如多指、畸形脸） | 12.3.3、14.3 模板 |
| **seed 随机种子** | 换种子=让AI重新抽签生成不同结果 | 18.2 QC失败重试时换种子 |
| **遮幅（letterbox）** | 在16:9画面上下加黑边，变成2.39:1宽银幕 | 本片全片统一 |
