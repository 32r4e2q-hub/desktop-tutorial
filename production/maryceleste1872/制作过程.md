# 制作过程 —《玛丽·赛勒斯特号：海上最大的未解之谜》三分钟 3D 动画短片

本片按用户提供的完整脚本（全局设定 + 8 段分段脚本 + 29 个镜头 + 合成规范）制作，
走北九洲案模版（`production/kitakyushu2002`）的工程流程，视频生成用智谱免费档
CogVideoX-Flash（`generate_cogvideox.py`，零费用）。本文档记录从脚本到成片的每一步、
相对模版的引擎改动，以及踩坑实录。

---

## 2. 内容单一出处

`build_story.py` 是唯一内容源：8 章解说（中文数字读法）、31 镜七元组（提示词/时长/运镜/
旁白/字幕/BGM/音效）、横幅大字（「十个人，凭空消失」等）、红叉事件、片头尾卡、发布文案。
`python3 build_story.py` 产出 `story.json`，`--script` / `--publish` 另出抖音脚本与发布文案。
所有提示词在生成前自动拼接【STYLE】，出现人物/船时拼接对应【角色设定】/【船体设定】，
每镜末尾自动追加【NEGATIVE】（禁静态图加推拉，必须真实运动）。

史实口径逐句来源与冲突裁决见 `史实核对.md`（日志 11/24 vs 25 取「十天前」、爆燃实验不点名、
Dei Gratia 译「上帝的恩典号」等）。

## 3. 角色与场景定稿（参考图）

`cast.json` + `production/face_cast.py` 管理 4 个角色脸 token+seed（C1 布里格斯船长 /
C2 莎拉 / C3 苏菲亚 / C4 摩尔豪斯船长，seed 18721107–18721204），生成定妆参考图：
C1–C4、完好/幽灵态玛丽号、上帝的恩典号、夜雾场景（`cast/`），PIL 拼 `定稿总览.jpg`。

跨镜一致性策略：免费档拒收 image_url（实测），31 镜纯文生，靠 face token + seed 保脸，
`face_cast.py check-prompts` 做画面闸门 + 人眼复核。**face_cast 曾误判多角色同框为偷带**，
已修（同镜头已声明的其他角色不算偷带）并加回归测试。

## 4. 配音与字幕时序

1. `generate_speech`（voice-00，悬疑低沉男声，讲故事语气）→ `audio/raw/N01–N08.mp3`；
   「都消失了」「绳子断了」处 0.5 秒停顿按脚本执行。
2. `tighten_pauses.py` 收紧句间停顿（CAP 0.45）：111 秒紧凑版。
3. `clause_times.py` 61 分句对齐（**align 重写**：比例 + 停顿吸附，旧能量 DP 在语速不均
   的配音上会挤出 10–15 字/秒的错切，已弃用；小句 <3 字并入前句）。
4. `pacing.py`（**新增引擎件**）把紧凑语音铺进 8 个章节窗口：句间停顿 0.26–3.22 秒
   （即悬疑呼吸位），tempo 全 1.000 不硬变速；防重复铺开保险（gap_before 二次跑不再摊开）。
   `audio/pacing-report.json` 记每章 speech/gap/sha256。
5. 字幕：白色黑边底部安全区，逐句同步；关键词金色高亮放大（`\fs92`），不遮主体，
   主体走三分线。TEMPO 表 0.78–1.15。

## 5. 切点与出片

- `tools/plan_cuts.py` 按镜目标 + 停顿中点锚点排 CUTS（31 镜全合法，如 S16 6.99s /
  S19 9.58s / S20 7.05s；首镜 DP 起点漂移 bug 已修）。
- `clause_times.py --check-cuts`：45/45 切点全绿。
- `render.py`（见下节改动）+ `score.py` 合成：画面叠字/调色/段界压黑、分段 BGM 压
  -18dB、8 类音效、爆燃处 BGM 静音 1 秒、收尾末秒静音。
- 转场：同段内硬切或叠化，段间 0.22–0.3 秒黑场或海雾。

## 6. 相对北九洲模版的引擎改动清单

| 模块 | 改动 |
|---|---|
| `pacing.py` | 新增：紧凑语音→章节窗口铺排（含防重复铺开保险） |
| `clause_times.py` | align 重写：比例 + 停顿吸附 + 小句并前句（弃用能量 DP） |
| `clause_times.py --check-cuts` | 窗口按 gap_before 自适应 |
| `tools/plan_cuts.py` | 按镜目标 + 停顿中点锚点；首镜 DP bug 修复（只允许 idx[0]==0 且 span 从 0 算） |
| `render.py` | 逐章窗口排版；横幅大字（`\an5\pos` 钉位防字幕碰撞挤掉）；红叉事件；金色放大关键词；段界 0.22s 压黑；段界=下章口播起点的 EDL（修 0.35s 断缝）；GRADE_OVERRIDES（S16 红 / S19 泛黄 / S17 灰）；VIGNETTE S06；FADE_OUT S20；片尾卡金色版式；write_sfx 扩 8 类；delogo 坐标按输出缩放 |
| `score.py` | 分段配乐接入（大提琴/弦乐/诡异钢琴/鼓点/管弦/悬疑钢琴/收尾）；包络 bug 修复（相对时间衰减） |
| `face_cast.py` | 多角色同框误判修复 + 回归测试 |
| `generate_cogvideox.py` | 容量熔断：429/1305 连拒 ~33 分钟判供应商容量满，记 `provider_capacity` 后 exit 42（原先直接崩溃 rc=1 被判真故障，没人接力）；轮次预算耗尽同样走 42 |
| `auto_resume.py` | main() 指到本片 marker `COGVIDEOX_GEN_REQUEST`，加 `--stale-stop` |
| 生成工作流 | 收尾接 auto_resume：rc=42 时记账 round+1 并 push marker 自触发下一轮（断点收据防重复生成），连零 10 轮或真故障（rc=1/43）停 |

## 7. 生成与质量闸门（CogVideoX-Flash 免费档）

- 触发：仅 push marker（`COGVIDEOX_GEN_REQUEST`）或 workflow_dispatch；
  **marker 后勿随意 push 同分支**（concurrency cancel-in-progress 会砍掉在跑的生成）。
- 同提示词重抽必须带 `force`（默认按 request_hash 复用收据）。
- 断点：SHA-256 收据 + previous_results 历史恢复，续跑不重复花钱。
- QA：每镜出 `qa/Sxx.jpg` 接触表 + `qa/Sxx.json` 元数据；坏镜用 `{"only":"Sxx"}`（同提示词加 force）重抽。
- 画面闸门：`face_cast.py check-prompts`（静态脸检）在生成前跑；人脸/伪文字需人眼复核原始像素。

**2026-10-22 实况**：首轮生成 run 39719464828 在 S01 提交遇 429/1305「该模型当前访问量过大」
19 连拒 26 分钟后崩溃（rc=1）；已按上表接线容量熔断 + 接力续投并重新触发（run 39733003337），
生成链自行排队等容量，出齐 31 镜为止。

## 10. 踩坑实录（防复发）

1. **ASS 转义事故**：f-string 单反斜杠被 Python 吃成换页符；用 `chr(92)` 拼 ASS 标签常量。
2. **横幅被吞**：无 `\pos` 的 Banner 事件被字幕碰撞规避挤掉；`\an5\pos(960,880)` 钉位。
   花哨背景+缩图会误判"没渲染"，先数金色像素再下结论。
3. **score.py 包络**：绝对时间算 exp 衰减→全静音；改相对时间 `t-t0`。
4. **plan_cuts 首镜 DP**：`dp[0][p]=0` 允许首镜漂移撑爆乒乓容量；只允许 idx[0]==0。
5. **make_edl 断缝**：章末取 window_end 与下章口播起点差 0.35s；章末=下章 narration start。
6. **eq 滤镜**：colorbalance 参数不能塞进 eq=…，要 `eq=…,colorbalance=…` 链式。
7. **能量 DP 切句**在语速不均配音上挤出 15 字/秒，弃用。
8. **pacing.py 重复跑**会二次铺开；先 tighten+clause_times 回紧凑版再重铺。
9. 沙箱无 ffprobe（media.probe 走 pyav）；apt 不可用，字体走 npm @fontsource woff2 →
   fontTools 转 TTF 合并到 `.cache/fonts/`；`pip install` 须 `--break-system-packages`。
10. 生成失败诊断会由工作流 commit 到 `gen-diag-cogvideox.log`（沙箱读不到 Actions 日志）。
11. **GHA `bash -e` 吞 rc 捕获**：`python | tee` 失败即整步退出，后面的 `rc=${PIPESTATUS[0]}`
   根本不执行；接力步读到兜底 rc=1。生成步要先 `set +e` 再跑 pipeline。
12. **decide() 短路顺序**：rc=1「真故障」判在 `phase==provider_capacity` 之前，会把生成器
   自己盖的容量熔断章丢掉；phase 是更权威的证据，先看 phase 再让 rc 说话。
13. **GITHUB_TOKEN 的 push 不触发 on: push**（GitHub 防递归）：接力步光推 marker 不会起
   下一轮，必须 `gh workflow run` 自派发（workflow_dispatch 是官方例外；工作流权限要
   加 `actions: write`）。
14. **模板里的「46 张全帧表」硬编码**是老项目段数：`publish_visual_review_bundle.py`
   应按 `manifest.json` 的 sheets 清单对账，段数因项目而异（本片 31 镜+片尾卡）。
15. **换声会顶破静音闸门**：`build_audio.assert_audible` 要求整轴静音占比 ≤2%（-50dBFS
   窗），voice-01 句间停顿更疏直接干到 2.2%。解法是整轴海风底床（-41dBFS 持续海浪+
   风声，织进 write_sfx），不砍悬疑呼吸、不动「爆燃 BGM 静音 1 秒」规格。
