## 本版规格与边界

- 目标成片：1920×1080 / 30 fps / 180 秒；45 镜（38 个 Agnes 动画镜头 + 7 张信息卡），每镜一次。
- 当前旁白：6 段，共 786 字（含标点）。`story.json`、`audio/manifest.json`、`screenplay.md` 必须逐字同步。
- 当前渲染音轨：`audio/N01.mp3`—`N06.mp3`；原始 TTS 在 `audio/raw/`，停顿处理记录在 `audio/tighten-report.json`。
- 全部生成画面均标为「AI 动画情景重现 · 非新闻影像」；不冒充档案或新闻。
- 巴斯德、迈斯特、母亲和医生只以背影、剪影或手部出现；不生成可识别真实人物面孔。
- 不展示遗体、伤口、血腥、实际注射或侵害过程；中文文字和日期均由后期添加。
- 巴斯德团队先通过兔间连续传代获得稳定的固定病毒，**再以感染兔脊髓的干燥降低毒力**；两步不得倒置。
- 巴斯德不是执业医生；1885 年首针由医生雅克—约瑟夫·格朗谢执行。
- 十三针 / 十四剂在权威史料的计数不同，成片只保留「十天、十几针」。
- 本片是历史与公共卫生科普，不替代医疗建议；潜在暴露后先用肥皂和流动水彻底清洗，再尽快联系当地医生或公共卫生机构评估。

## 出片闭环

工作流固定到当前分支；模板副本在 `workflows/`，GitHub 生效副本在 `.github/workflows/`。只有每一步证据齐全后才进入下一步。

1. **内容与音频闸门**

   ```bash
   python3 production/rabies1885/build_story.py  # 仅当改了唯一内容源时；会重写 story/manifest 的文本
   python3 production/rabies1885/generate.py --validate
   python3 production/rabies1885/clause_times.py --check-cuts
   ```

   修改旁白后必须重新生成对应配音、收紧停顿、重算分句时间和 SHA-256；不能用旧音频或旧字幕凑合。

2. **局部素材重生与复核（只在发现确定缺陷时执行）**

   当前 9 镜修订已完成；**不要为了重跑而重跑**。只有确认镜头含有人脸、可读伪文字、畸形肢体、中途换场、黑帧或不当暴力时，才修改该镜请求并用 `GEN_REQUEST` 重做。例如：

   ```json
   {"workers": 1, "only": "S40", "revision": "describe-the-confirmed-defect"}
   ```

   重做后必须重新查看该镜 `qa/Sxx.jpg` / 接触表，且 `results.json` 的 `request_hash` 必须与 `story.json` 一致；再触发重渲、听检与全帧 QC。不能拿旧成片的报告替代新成片证据。

3. **渲染与交付报告（当前版本已完成）**

   `rabies1885-render.yml` 已将当前来源、实测配音、字幕、EDL、音频/技术报告写回 `交付/` 与 `delivery/`。任何镜头改动后，才改写 `RENDER_REQUEST` 触发重渲；新报告的 SHA-256 必须与新 MP4 一致。

4. **逐字听检、逐帧 QC 与人工签收（最后一道未闭合闸门）**

   当前 `VERBATIM_REQUEST` 与 `VISUAL_QC_REQUEST` 都已完成：六章 CER ≤ 0.15，视觉工作流已解码全部 5400 帧。接下来要按 EDL 逐段检查画面与字幕、在切点前后 0.25 秒核对字幕切换，并复核完整接触表中的异常候选。只有人工确认没有语义、构图、伪文字、脸部或手部问题，才可把 `human_semantic_visual_review` 更新为 `approved`、上传当前 SHA 对应的 Release 资产。任何确认缺陷均回到对应步骤修复并重渲。

## 文件职责

| 路径 | 作用 |
|---|---|
| `build_story.py` | 唯一内容源：旁白、45 镜、信息卡、字幕关键词、发布文案和事实来源 |
| `story.json` | 机器可读时间线和镜头计划；由内容源生成 |
| `audio/manifest.json`、`audio/N0*.mp3`、`audio/clause-times.json` | 渲染用配音、哈希及分句时间 |
| `results.json` | Agnes 请求、素材 URL、请求哈希与 SHA-256 回执 |
| `generate.py` | 完整性闸门、增量 Agnes 生成和来源回执 |
| `render.py` / `../run_project.sh` | 剪辑、字幕、混音、成片技术复测与写回 |
| `workflows/` / `.github/workflows/` | marker 工作流模板 / GitHub 生效副本 |
| `delivery/`、`qa/`、`交付/` | 新出片后生成的审核证据与成片；旧产物不可作为新版本证据 |

`制作过程.md`、`解说词体检.md` 是历史日志或已作废的旧版本材料；不作为当前的事实或交付状态依据。
