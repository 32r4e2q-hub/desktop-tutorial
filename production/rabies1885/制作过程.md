## 2. 第 0.5 步｜参考片量风格（`production/style_lab/`）

上传 `monalisa_180_web.mp4`（65.2 MB · 1280×720 · 25 fps · 180 秒），抽 48 帧 + 整段硬切检测，
实测（`runs/20261004-073904-monalisa_180_web/reference_metrics.json`）：

| 维度 | 实测 | 判定 |
|---|---|---|
| 主色 | 近黑 `#1a160d` 33% · 棕褐 `#554e32` 26% · 橄榄 `#87805e` 19% | 暖褐 / 羊皮纸 |
| 影调 | 平均亮度 92/255 | 暗调 |
| 反差 | 帧内标准差 68 | 强反差 |
| 色温 | R−B **+28** | 暖调（琥珀 / 钠灯） |
| 颗粒 | 高频残差 13.21 | 明显胶片颗粒 |
| 运动 | 帧间差 0.079 | 明显运动 / 手持感 |
| 节奏 | 33 次切换 · 中位 5.77 秒 | 从容（**新片不跟，仍按 45 镜 × 4 秒**） |

选 `photoreal_silhouette`（超写实 3D · 人物只背影 / 剪影 / 手部，与手册护栏一致），
把调色 / 光线 / 颗粒词三份共用，写进 `build_story.py` 的 `STYLE_PREFIX`。

**两处刻意的偏离，记在这里**：

1. 景深：参考片实测 0.44（边缘比中心锐），`style_lab` 自己判定为「主体靠边或素材偏平」，
   不是真实景深读数——所以提示词里用 `natural cinematic depth`，没照抄 `flat even focus`；
2. 负面词：吉尔戈那部的 `NEGATIVE_PROMPT` 里有 `3D render look, plastic CGI`，
   照抄会把这次要的超写实 3D 自己否掉，换成 `flat 2D illustration, hand-drawn cel shading…`。

## 3. 第 1 步｜史实核对（`production/docs_lab/`）

工作区 `rabies1885`：上传 `史实核对.md`（9 条来源，2026-10-04 联网核对）当资料，
再把改编后的解说词传上去做体检，两者互相指着说话。

来源：WHO 实况报道 · 美国 CDC MMWR · 巴斯德研究所官方史料 · 《柳叶刀》 ·
《Pasteur and rabies: the British connection》(SAGE) · 《Medical History》1982 综述 ·
国家疾控局《狂犬病暴露预防处置工作规范（2023年版）》。

### 与用户上传文案的对照（五处改动）

| 上传文案 | 核对结果 | 处理 |
|---|---|---|
| 「死亡率百分之百」 | WHO：出现症状后 100% 致死，成立 | 保留，写成「几乎就是百分之百」 |
| 「血肉模糊的伤口特写」 | 画面踩血腥红线，TTS 也会拦 | 删；改成狗的剪影 + 事后绷带 |
| 「活活烧死或闷死」 | 闷死有出处（Saint-Tügen 礼拜堂、《柳叶刀》综述），烧死没有 | 改成「烧灼伤口，甚至把病人闷死」 |
| 「整个医学界都在嘲笑他」 | 无出处 | 改成「同行质问他：病原体都看不见，你凭什么」 |
| 「巴斯德在日记里写下折磨」 | 无出处 | 换成 CDC 转引的巴斯德原话 |
| 「整个巴黎都在盯着」 | 无出处 | 换成有出处的数字：1886-11 约 2500 人、到 1895 年近 2 万人 |

针数两份权威来源不一致（CDC 十四剂 / 巴斯德研究所十三针）→ 成片只说「十天、十几针」，不写死数字。

## 4. 第 2 步｜解说词

769 字 / 六章，分章字数 **116 / 142 / 144 / 114 / 129 / 124**（吉尔戈是 109/106/142/125/164/139）。
`production/rabies1885/解说词体检.md` 是体检报告（章数、字数、时长、TTS 风险词、逐句出处映射）。

`screenplay.md` 改为**由 story.json 渲染**（`build_story.py --screenplay`），
不再手工抄——三处逐字一致（`screenplay.md` / `story.json` / `audio/manifest.json`）
靠生成器保证，不靠人。

## 5. 第 3 步｜45 镜

38 个 Agnes 镜头 + 7 张信息卡（病死率 / 人物档案 / 日期 / 疗程 / 扩散数字 / 今天仍在 / 接种程序）。
按章节分：N01 七镜、N02 六镜、N03 七镜、N04 六镜、N05 六镜、N06 六镜。

红线怎么落的：被咬只用狗的剪影与事后绷带交代，**不重现撕咬**；病人只用椅子上的剪影、
床、灯、门窗光暗示，不出现病容；真实人物（巴斯德、约瑟夫、母亲）只以背影 / 手出现；
画面里一律无可读文字（铜牌、标签、门牌、列车车身全部留白）。

## 8. 第 6.5 步｜曝光事故（这一部最大的坑）

第一轮 38 镜全部废掉，原因在风格前缀：写了 `near-black, sepia brown, olive, dim, moody exposure`
这种**调色板描述**，模型照着把整帧压到接近全黑。

同管线实测（接触表 2 fps / 384×216，和成片素材走同一条 ffmpeg 管线）：

| | 亮度 | 反差 | 色温 | 颗粒 | 运动 |
|---|---|---|---|---|---|
| 用户参考片 | 85–97 | 55–82 | +15~+33 | 10–13 | 17–29 |
| 已出片吉尔戈（38 镜中位） | 84 | 44 | −20 | 8.2 | 16.4 |
| 已出片黑色大丽花（24 镜中位） | 56 | 47 | +20 | 5.3 | 16.3 |
| **本片第一版** | **14–17** | **16–19** | +16~+24 | 2.6–3.4 | 6–7 |

改法三步，每一步都是量出来的：

1. 全局前缀不再写「暗」，改成可执行的曝光口径：中间调 35–45% luma、暗部压深但留细节、
   每个内景至少两处光源；负面词挡住 `underexposed / crushed black shadows / almost entirely black frame`；
2. **曝光收尾挂在逐镜描述之后**（`LIGHTING_SUFFIX`）——全局前缀在前面，会被逐镜的
   "a single oil lamp" / "everything else in near-darkness" 顶掉，S06 / S27 / S33 都是这么翻的车；
3. 色温：正确曝光 + "warm amber-tungsten" 让整片偏橙（42–68，参考片 28），
   改成 warm but natural / amber highlights / no overall orange cast，现代那几镜再单独改中性光
   （1885 琥珀、今天中性，形成对比）。

最终全片：亮度中位 **63**（区间 31–114）· 色温中位 **+43** · 运动 **20.3**。
色温仍比参考片高 15 个单位，是这一部接受的偏差（琥珀色调本来就是要的）。

## 9. 第 7 步｜自动检验（`qc_shots.py`）

代理看不到画面，所以把能机器判的部分全做了：黑帧 / 冻结 / 中途换场 / 露脸（BlazeFace）/
手（MediaPipe Hands）/ 肤色占比 / 亮度·反差·色温·颗粒·运动（按同管线基准分硬线与警戒线两档）。
判据是校准出来的，不是拍脑袋：

- 人脸最初按「置信度 0.6 + 框宽 3%」判，S01（画面里只有一条狗的剪影、没有任何人）报了 6 格，
  全是误报 → 改成 0.75 + 框宽 6%，且「多格持续出现或 ≥ 0.9」才算硬伤，单格转 WARN，
  并把疑似区域裁到 `qa/faces/` 给人眼看；
- 肤色占比在暖调画面里会虚高（木墙、琥珀灯光都落在肤色区间）→ 阈值抬到 0.5，并注明仅供参考。

最终结果：38 镜 **FAIL 0 / WARN 32 / PASS 6**。WARN 集中在两类需要人眼确认的：
画面里有手（AI 最容易畸变的部位）、色温偏暖。

## 10. 第 9 步｜出片

`RENDER_REQUEST` 触发，成片 180.0 秒 / 1920×1080 / 30 fps / H.264 + AAC /
46 个剪辑段 / 38 个源片段无复用 / 音频 −20.5 dBFS（峰值 −1.53）/ 变速比 1.062。

出片后本地跑了 `production/review_film.py` 复检：

- 14 帧接近全黑 → 全在片头淡入（0–0.07 s）与片尾淡出（176.2 s、179.7–180 s），设计如此；
- 30 处「1 秒几乎无变化」→ 8 处复核为真静止（7 张信息卡 + 片尾卡，本来就该静止），
  22 处是 16×16 阈值过严造成的误报。
