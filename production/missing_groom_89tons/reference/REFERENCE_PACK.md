## 质检标准（逐张过）

1. 写实比例：人体比例、五官、手指正常，无双头/多肢/糊脸。
2. 材质真实：皮肤有毛孔与自然高光，布料有织纹褶皱，水泥/油漆/水渍有厚度。
3. 风格铁律：无卡通、Q 版、动漫、夸张表情；低饱和、暗部厚重、胶片颗粒。
4. 无文字：所有可读文字、水印、字幕、时间戳、标签一律不得出现（抽象线条可以使用）。
5. 平台安全：无遗体、血腥、伤口、行凶过程；卫生间/油漆/沙发只作空镜与物件暗示。
6. 角色一致性：C01–C10 统一浅灰棚拍背景、三视图；C03 半脸阴影；C10 剪影+双人同貌。

## 定稿规则

- 任一张不合格即重生成，不用“凑合”的图；同一 ID 重生成后必须更新 `approvals.json` 的 SHA-256。
- 全部 30 张定稿后，把 PNG 提交到当前分支，把该提交的 40 位 commit SHA 写进 `revision.txt`，
  再触发 GEN_REQUEST —— Agnes reference 模式只认这条不可变链接。
- 每 5 镜回看一次成片抽帧，若面部/服装漂移，回到本表重挑参考图并重生成该镜。
