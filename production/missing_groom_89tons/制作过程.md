# 制作过程 · 消失的未婚夫：一个月八十九吨水（第 13 期）

时间：2026-11-12（单日完成）｜工具链：仓库默认模板 `production/setagaya2000` + 已交付先例 `production/honeymoon_nicotine`
产出：1080p / 24fps / 180.000s / 30 镜 / 74.5 MB 成片 + 系列封面 + 字幕 + 技术报告

## 一、决策：走 reference 模式，而不是世田谷的文字模式

剧本给了 10 个角色锚点、13 个场景、7 个道具，并要求「人物一致」。世田谷模式靠文字 prompt 锁不住脸，
所以照蜜月案做成 `mode=reference`：30 张参考图（C01–C10 三视图 / S01–S13 场景 / P01–P07 道具），
Agnes 每条镜头吃 1–4 张不可变 raw 链接。代价是前置多两天工作量，收益是 30 镜里同一张脸没漂。

## 二、流水线（每一步都能重跑）

```
build_story.py           30 行镜头表 = 30 句旁白 + 视觉点 + 参考 ID + 角色 + 运镜 + 音效
  → story.json / screenplay.md / 抖音脚本.md / 抖音发布文案.md
参考图 30 张 → approvals.json(SHA-256) → revision.txt(40 位 commit)
  → GEN_REQUEST {"mode":"clips","workers":2} → 30 条 Agnes 2.5 Flash 720P 片段 + qa/Sxx.jpg 接触表
旁白 30 条（voice-01）→ build_audio_manifest.py → audio/manifest.json
  → GEN_REQUEST {"mode":"render"} → render.py → qc.py → narration_fit.py → 交付/
  → production/verify_master.py 独立复验
系列封面 → mystery-cover-template/generate_cover.py --episode 13
```

## 三、实际耗时结构（为什么先排队 30 个片段）

| 阶段 | 耗时 | 说明 |
|---|---|---|
| 剧本 → 30 镜内容源 | ~30 min | 605 字旁白，3.1–4.0 字/秒，全部落在镜长内 |
| 30 张参考图 | ~25 min（分 3 批，单批 10 张上限） | 逐张拼版复核，1024px PNG，28 MB |
| 30 条片段排队 + 回收 | **~2 h 10 min** | 关键瓶颈：Agnes 队列一次只放 5 个在途任务，12.1 s 闸门下每条约 70 s；满了自动 60 s 退避 |
| 旁白 TTS | ~10 min | 30 条，最大 1.28× 变速，无截字 |
| 合片 / QC / 复验 | ~9 min × 3 轮 | 三轮都是因为下面两个真故障 |

结论：**先把 30 个最慢的片段排进队列，再去做旁白、封面和文档**，这是这套流程唯一的正确顺序。

## 四、两次真实故障（修完都变成了闸门）

### 1. 成片 180.000 s，但音频流只有 177.834 s，最后一句被吃掉 1.2 秒

- 发现方式：新加的 `render.py` 后置断言读**音频流**时长，而不是容器的 `format.duration`。
- 根因：runner 上的 ffmpeg 4.1 在一次「视频+音频」混合编码里丢了尾部音频；本地 ffmpeg 9 复现不出来。
- 修法：画面（含烧字幕）与旁白分别编码，最后 `-c copy` 合并；旁白轨先 `apad` 到 180.000 s。
- 结果：`PICTURE 180.000s VOICE 180.000s MUXED 180.000s`，`qc.py` 也加了同样的硬失败。

### 2. 字幕比语音早 0.3 秒

- 发现方式：对成片音频做 10 ms RMS 包络，逐条量 cue 起点与真实语音起点。
- 根因：cue 从 mp3 文件起点算，而 TTS 文件开头有 0.3 s 前导静音。
- 修法：每段先 `silenceremove=start_threshold=-50dB` 再 `atempo`，cue 用去静音后的实际语音时长；顺带把每段用 `-t` 钉成精确时长。
- 结果：领先量降到 ≤0.13 s，`verify_master.py --max-lead 0.20` 卡死这类回归。

### 3. 附带的第三个坑：模型自绘伪标题

S30 提示词里写了「金色标题后期添加」，Agnes 就真在画面里画了伪中文标题（叠在我们自己的片尾卡上）。
改法：提示词不出现「标题/字幕」，显式写「没有任何文字、字形、字母、招牌」，`{"mode":"clips","only":"S30"}` 单镜重生成。
**改负向词会改所有镜头的 request_hash，等于重跑 30 条**——所以要单镜修，就别动全局 NEGATIVE。
