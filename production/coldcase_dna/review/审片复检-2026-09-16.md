  证据图见本目录 `review-round2-before-1/2.jpg`（每格=一个镜头的 6 帧连拍）。

## 复检结论：v1 的两类硬伤

### 一、镜头中段「场景漂移」（畸变的一种，最严重）

大量素材在 7 秒的后半段**自己换场景**：法庭变档案室、街景变实验室、证物袋变实验台。
这是生成端没有把「单一场景」钉死。受影响镜头（复检判定「重生成」）：
S01 S02 S04 S05 S06 S09 S11 S12 S14 S17 S19 S21 S22 S24 S26 S28 S30。

### 二、运镜飞来飞去

- `S07`：镜头绕侦探环接近 180°（正面→侧面→背面→另一侧），即用户说的「飞来飞去」；
- `S09`：实验室里快速前冲；
- `S28`：过肩**后撤**运镜诱发了人头与身体朝向错乱（2:42 处），且随后整段漂移成档案室。

复检判定可保留的 6 镜：**S10 S15 S16 S20 S25 S29**（单场景、无畸变、运镜平稳）。

## 对策（全部落在 story.json 的提示词里，可逐条核对）

1. **18 个重生成镜头的提示词重写**，参照 db 库珀案奏效的写法：
   - 场景描述放最前（v1 全部以「Camera: …」开头，把运动当成了主角，是漂移诱因之一）；
   - 每条提示词显式写死：**locked off / 锁定机位、背景与陈设全程不动、
     no scene change / 全段不换场景、no readable text**；
   - 人物镜头一律**背影/侧面固定/过肩固定**，写明「全程同一坐姿、不起身、不转身、
     镜头绝不绕到另一侧」——从结构上杜绝「人头跟身子反了」；
   - 运镜只保留 db 库珀式的小幅动作：横向慢移、微距固定、俯拍固定、航拍悬停缓移，
     **删除环绕、过肩后撤、快速推进**。
2. `principles` 增加一条运镜克制原则，后续新题目沿用。
3. 可保留的 6 镜提示词一个字未动——`request_hash` 不变，出片时按 SHA-256 原样复用素材。

## 重生成后的验收流程（不变）

1. 「冷案DNA · Agnes生成」只重生成 18 镜（75 秒节流，断点续跑）；
2. 素材 artifact 下载后**逐镜 6 帧复检**（同一标准：单场景、无畸变、运镜平稳），
   不合格的单独 `{"only":"Sxx","workers":1}` 重做；
3. 全部合格后才 bump `RENDER_REQUEST` 出片；
4. 出片后 `production/qc_film.py` + 逐字听检，再发 Release。

  - `S30`：前 1.5 秒微距正确，之后漂移成档案桌图纸 → 实验室 → 研究员。

### 三轮漂移治不好的根因分析

对照 db 库珀案（用户点名参照，25 镜复检全过）的提示词逐条比对，差异是结构性的：

| | dbcooper（全过） | coldcase 三轮失败镜 |
|---|---|---|
| 长度 | **37–100 词** | 95–110 词 |
| 结构 | 场景 2–4 句 + 一行 `Camera: …` + 至多一句收尾 | 场景 + 大段 "never / stays the same / like a photograph" 防御从句 |
| 否定名词 | 无（只有安全的 "No faces / No readable text"） | 成串（no cameras/tripods/scene change/people…） |
| 动作锚 | 每镜有一个具体小动作/小运镜，画面有「事」可做 | 追求「一张照片」，纯静态空镜，模型自己「加戏」换场景 |

结论：**防御式长提示词防不住漂移，纯静态空镜反而诱发漂移**；
db 库珀的短句 + 单一动作锚才是奏效写法，且 `Camera:` 裸写从不穿帮
（穿帮只发生在否定句里出现 camera/tripod 名词时）。

### 第四轮对策（已落 story.json，可逐条核对）

`S01 / S09 / S24 / S30` 四镜提示词整体重写为 db 库珀结构：

1. 场景 2–3 个具体名词短语开头，总长压到 **60–68 词**；
2. 运镜一行 `Camera: …`，沿用 dbcooper 复检通过的原句式
   （locked-off / almost imperceptible slow drift）——尊重用户
   「不要飞来飞去」的要求，只保留毫米级动作；
3. **每镜给一个动作锚**（雾在灯柱间飘 / 仪器指示灯轻闪 / 暖霭缓移 /
   玻璃螺旋缓慢自转发光呼吸），让模型有「事」可做，无暇换场景；
4. **零否定名词**：删光 no cameras / no tripods / no scene change /
   nothing enters 之类从句，只保留两轮实证安全的 "No people / No readable text"；
5. seed 微调（+7）脱离连续三轮的漂移模式；S07 一字未动。

第四轮只重生成这 4 镜（`{"only":"S01,S09,S24,S30","workers":1}`），
复检合格后 bump `RENDER_REQUEST` 出片。

## 第五轮（S30 缓推微距，失败）

把第四轮的「锁定机位」改成 dbcooper S06 式「macro slow push」动作锚：
结果更糟——缓推给了模型「后退揭示环境」的动力，1.5 秒后一路拉远成
台灯房间→白大褂研究员→古董仪器桌，还引入了人物。

**五轮四漂的结论**：「桌面纯微距静物」是这个模型最不稳的题材
（5 次独立生成 4 次漂移成房间/人物），怎么写提示词都大概率漂，
放弃该题材。

图片公网 URL，本仓库私有、raw 链接未认证 404，路线不通。
