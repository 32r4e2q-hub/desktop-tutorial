## 文件与复现

- `build_story.py`：唯一内容源；`facts.md`：事实依据与改编边界。
- `reference/manifest.json`：31项资产清单；`reference/review.json`：实际检查记录。
- `generate.py`：Agnes请求、参考图审核闸门、5镜审核闸门、断点续跑与收据校验。
- `render.py` / `build_audio.py` / `qc.py` / `narration_fit.py`：世田谷合成与质检副本，已换项目常量；尚未做本案端到端媒体验证。
- `.github/workflows/crippen1910-gen.yml`：云端生成与合成工作流，marker触发；当前**没有**GEN_REQUEST，不会误启动素材生成。

```bash
python3 production/crippen1910/build_story.py
python3 -m unittest production.tests.test_crippen1910 -v
```

完整参考资产审核后，在 `reference/approvals.json` 记录每项 `status=approved` 和实际 `sha256`，以及图片所在不可变Git提交 `revision`。该文件当前不存在，故素材生成闸门按设计关闭。

云端批次请求（仅在参考包完整且审核后使用）：

```json
{"mode":"clips","only":"S01,S02,S03,S04,S05","workers":2}
```

把请求写到 `production/crippen1910/GEN_REQUEST` 并推送当前固定分支。随后逐5镜审核，在 `qa/batch-reviews.json` 记录每镜实际素材SHA与 `status=approved`；再启动下一批。禁止自动批量越过审核。
