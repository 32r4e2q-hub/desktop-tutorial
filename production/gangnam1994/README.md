# 第十四期｜江南豪门双尸案：报警的人，是凶手（30 镜 / 180 秒 / Agnes Video 2.5 Flash）

抖音横屏 16:9、1920×1080、24fps、180.000 秒、30 个真实连续运动的**写实 3D 动画**镜头。
沿用仓库 `production/missing_groom_89tons/`（第 13 期 30 镜 `mode=reference` + 音画同步闸门）最新工具链与手册标准。

## 核心规格与安全原则

- **模型与限流**：`agnes-video-2.5-flash`，源片 `720P`（Lanczos 放大至 1920×1080），`mode=reference`，`seconds` 字符串（5/6/7），共享请求闸门 `12.1s`（月卡每分钟最多 5 次请求，一次性顺序排队 30 镜 + 双 worker 回收）。
- **参考图定稿包**：31 张（9 角色 C01–C09、15 场景 S01–S15、7 道具 P01–P07），逐张人工检查后写入 `reference/approvals.json`（SHA-256），并钉死在 `reference/revision.txt`（40 位不可变 commit SHA）。
- **平台安全与尊重原则**：全片绝不出现行凶、血腥、伤口、遗体、裸露或凶器特写；案发仅用熄灯、关门、火光、清澈淋浴蒸汽、切黑克制暗示；所有角色为虚构演员式写实 3D 形象；左上角常驻“AI动画情景重现 · 非真实影像”。
- **防跳出留存设计**：前 10 秒直接进入起火与赤脚报警；全片按时间表精准烧录 H1–H9 大号钩子字幕 + 逐镜同步金色高亮字幕 + 分段电影色调演进 + 低频克制悬疑氛围音与关键点环境音效。
