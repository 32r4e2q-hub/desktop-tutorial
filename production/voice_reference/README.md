# 解说固定男音（全项目共用，焊死在工具链里）

本目录把「解说用哪把声音」钉死：**普通话男音，与《黑色大丽花》《十二宫杀手》同款**。
开新题目不需要再问用户要音色——按下面的规程做，做完过闸门。

## 为什么钉死

《十二宫杀手》第一版成片的解说被配成了明显偏高的音色（实测中位基频
168–200 Hz，参考男音是 113–139 Hz），直到成片交付才被人耳发现，只能整片重配。
音色选择从此不再靠"每次试听都记得选男声"，而是：

1. **规程写死**（见 `spec.json` 的 `selection_procedure` 与《新题目开工手册》第 5 步）；
2. **机器闸门**（`production/check_voice.py`）在出片流程里量基频，不在区间内直接拒绝出片
   （`production/run_project.sh` 第 2/6 步）。

## 怎么配下一部片子的音

1. 试听（voice audition）时明确指定：**普通话（zh-CN）· 男声（masculine）· 解说（narration）**；
2. 候选声音先和本目录的参考样本对比——`dahlia_male_narration_N01.mp3` 就是那把男音的原声——
   选最接近的一个；两个都不像就换下一组重新试听；
3. 六段配音生成后，跑：

   ```bash
   python3 production/check_voice.py --project production/<slug>
   ```

   通过才允许进混音；出片流程里这道闸门是自动跑的，不过闸门流程直接失败。

## 参考样本与实测数字

| 文件 | 说明 |
|---|---|
| `dahlia_male_narration_N01.mp3` | 参考片《黑色大丽花》N01 原声（这把男音的出处） |
| `zodiac1969_male_narration_N01.mp3` | 《十二宫杀手》重配音 N01（跨片复现同一音色的实证） |
| `spec.json` | 机器可读规格：试听参数、实测基频、闸门阈值 |

实测（每章中位基频，Hz）：《黑色大丽花》113–139；《十二宫杀手》重配后 109–135；
被否掉的第一版 168–200。数字全部由 `production/check_voice.py` 同一套分析量出，
方法与阈值记录在 `spec.json`，不要手改。
