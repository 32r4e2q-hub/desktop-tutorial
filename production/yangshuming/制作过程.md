> 三分钟横版 3D 动画解说短片的完整制作记录。流水线与闸门沿用北九州模板（`production/kitakyushu2002`），
> 生成侧只走智谱 CogVideoX-Flash 免费档（仓库 secret `ZHIPUAI_API_KEY`）。

## 0. 输入

- 用户上传文案：`抖音文案/20261018-005748_粘贴的文案_20261018-005748.txt`
  （《红衣杀手杨树明》30 镜 × 6 秒脚本，含每镜中文旁白 / English prompt / 运镜 / 音效 / 事实核对参考）
- 模板：`production/kitakyushu2002`（北九州监禁案，CogVideoX-Flash 全流程跑通的参考实现）

  剧情跌宕起伏结合文案；镜头细腻；注意畸变、音画同步、解说与解说词/片段对应；多次校验出成片；
  配音由 agent 按剧情自定。

## 1. 内容改写（build_story.py）

- 用户稿口播共 1642 字，180 秒容量上限约 800 字——按模板六章结构压缩改写为 **788 字（含标点）**，
  六章：红衣之下 / 凶手没有消失 / 线索收拢 / 沉默被打破 / 判决与代价 / 留下来的。
  关键事实全保留：1992 马家坪首案、14 年 12 起 9 死 3 伤、「红衣杀手」媒体称呼、杨树明（寿阳/企业工人/
  有家庭）、2001 女工案、2004 冬、2005 专案组并案、2006.3 传唤与心理测试、3 月底前后交代、
  4 月告破、8.10 一审死刑（另因抢劫罪判有期，数罪并罚）、11.21 执行死刑、受害者 16—42 岁。
- 数字一律中文读法（一九九二年 / 十四人…）供 TTS 与逐字听检对齐。
- 30 镜文案扩成模板的 45 镜网格（38 动态 + 7 信息卡），分镜逐句咬合六章解说词。
- 露脸模式 3 个虚构匿名角色（C1 杨树明替身·非本人容貌 / C2 老刑警 / C3 法官），
  6 个露脸镜头登记，面容 token 从 cast.json 占位符注入保证逐字节一致；受害者只出物件与空椅。
- 事实核对：7 条公开来源（新华网一审稿 / 2006-11-22 执行报道 / 人民公安报·山西晚报「红衣杀手」侦破报道 /
  新华社 4.3 告破电 / 测谎与逮捕报道 / English Wikipedia / 知乎案情梳理），冲突口径见 `史实核对.md`：
  - 首案受害者年龄（16 vs 26）→ 解说不写年龄，只写「一名下夜班的女工」；
  - 末案日期（2004.11 vs 2005.02 vs 2006.02）→ 只写「二〇〇四年冬天」；
  - 「红衣」只写「有报道称多名受害者穿着红色衣物」，并强调比颜色更重要的是案件之间的联系。

## 2. 配音（voice-00，agent 按用户授权自选）

- Arena TTS 六段（男声低沉叙述，语感按「悬疑纪实」定）→ `audio/raw/N0x.mp3`。
- `tighten_pauses.py` 只剪静音不动字：183.29s → 170.37s；变速比 1.014（允许 0.86–1.10）。
- 第一版 N01/N03 分句对时出现 4 处语速异常告警（「一年，又一年」碎句、N03 首句过短），
  按手册「只能改措辞」的口径改写两处解说词并重生成 TTS，`--check-cuts` 全绿。
- `clause_times.py` DP 分句对时间写入 `audio/clause-times.json`；CUTS 由 `tools/plan_cuts.py`
  排骨架（45/45 切点落在分句停顿窗，0.00 偏差）。
