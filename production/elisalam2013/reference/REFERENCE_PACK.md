# 蓝可儿案参考图包

所有图都是生成式参考资产，不是真实案发照片，也不是蓝可儿本人的脸。C 图用于人物外观锚定（虚构演员式形象）；S 图用于环境；P 图用于道具。最终 Agnes 视频提示词仍由 `generate.py` 自动拼接 STYLE、逐字角色锚点、镜头描述和 NEGATIVE。画面一律不出现可读文字、水印、标识；人物一律为虚构华裔演员式面孔，禁止伪造可识别真实当事人/受害者/死者的肖像，禁止出现遗体、伤害动作、血迹。

**生成顺序：** C → S → P。每张图片单独生成、逐张读回目视检查；不符合设计或有伪字/多余肢体/不当内容时，针对同一编号重生成。仅经过检查并登记 SHA-256 的定稿可改为 `approved`。

## 固定 ID 与视频提示词限制

- 角色锚点原文见 `build_story.py` 的 `CHARACTERS`，`generate.py` 逐字插入，不要手动改写成真实人物特征。
- 任何参考图不得出现真实姓名、真实人脸、真实案发照片构图；Agnes 调用统一使用不可变 raw 链接（`reference/revision.txt` 指向的资产提交）。
- 新闻/录像母题镜头禁止生成可读新闻标题或录像画面文字；大字由后期烧录。
- 水箱、尸检、死亡过程一律不具象再现：参考图里只允许水箱金属、光、水汽、轮廓。
