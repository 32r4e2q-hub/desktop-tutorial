所有图都是生成式参考资产，不是真实案发照片或真实人物肖像。C 图用于人物外观锚定；S 图用于环境；P 图用于道具。最终 Agnes 视频提示词仍由 `generate.py` 自动拼接 STYLE、逐字角色锚点、镜头描述和 NEGATIVE。画面一律不出现可读文字、水印、标识；人物一律为虚构东亚面孔，禁止伪造可识别真实当事人/受害者/死者的肖像，禁止出现遗体、伤害动作、血迹。

## 固定 ID 与视频提示词限制

- 角色锚点原文见 `build_story.py` 的 `CHARACTERS`，生成时 `generate.py` 会逐字插入，不要手动改写成真实人物特征。
- 任何参考图不得出现真实姓名、真实人脸、真实案发照片构图；Agnes 调用统一使用不可变 raw 链接（`reference/revision.txt` 指向的资产提交）。
- 镜 28 新闻快切禁止生成可读新闻标题；大字由后期烧录。
