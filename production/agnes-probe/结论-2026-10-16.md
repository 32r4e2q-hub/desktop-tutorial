**一句话**：2.0 系列（含 `agnes-video-2.0-flash`）在平台上已经彻底没有通道了，不是"限时免费结束"，是模型没了。
免费档现在**唯一**能出片的视频模型是 `agnes-video-2.5-flash`（720P 固定、单条 4–12 秒）。

## 二、`agnes-video-2.5-flash` 的真实可用性：能过，但要分钟级抢

2026-10-16 07:48:09Z 的受理记录（`report.json` 里的 `attempts`）：

第 4 次  07:45:09Z  HTTP 503  video queue is full, please retry later

产出：`https://platform-outputs.agnes-ai.space/videos/agnes-video-2.5/task_7dSNNBCUzfnQQygImVbcQaMhG8Bfy0UT.mp4`
（`seconds: "4"`、`mode: "text"`、`size: "720P"`、`aspect_ratio: "16:9"`，全程 $0）

同一天 07:21 那一轮用 6 次重试、每次间隔约 60 秒（`agnes_video.create_task` 的默认退避上限就是 60 秒），
**6 次全部失败**；换成每 3 分钟一次，第 5 次就过了。10-12 那次也是 8 分钟内 6 次全灭。

**结论：队列满不是"模型坏了"，也不是"账号没资格"，是免费池子挤。退避窗口要按 10 分钟以上设计，秒级/分钟级重试不够。**

## 三、别把这几种失败混为一谈

| 返回 | 含义 | 该怎么办 |
| --- | --- | --- |
| 503 `model_not_found`（`No available channel`） | 模型没了 | 换模型，重试无用（`create_task` 现在会立刻放弃） |
| 403 `insufficient_user_quota`（`remaining: $0`） | 要钱 | 换 flash 档，或充值 |
| 503 `video queue is full` | 免费池挤爆 | **重试**，间隔 ≥180 秒，预算 ≥10 分钟 |
| 429 `rate limit ... for free users` | 撞到 1 RPM | 间隔 ≥60 秒 |

## 五、对本仓库的影响

- 6 个项目的 `generate.py` / `render.py` 里硬编码 `agnes-video-v2.0`（`agnes_video.DEFAULT_MODEL`），**现在跑一定失败**（503 `model_not_found`）。
- 迁移目标 `agnes-video-2.5-flash` 的参数形状不同：`seconds`（字符串 "4"–"12"）、`mode`（必填）、`size`（Flash 只能 `"720P"`）、`aspect_ratio`；不能再传 `num_frames` / `frame_rate` / `width` / `height`。
- 轮询要带 `&model_name=agnes-video-2.5-flash`；完成响应取顶层 `url`。
- 分辨率会从现在的 1920x1088 掉到 720P（16:9 → 1280x720），要 1080P 只能换付费的 `agnes-video-2.5`（约 $0.04/秒，一条 268 秒成片 ≈ $10.7）。

## 六、怎么复跑

零成本校验（不生成视频，只看模型名是否还存在 / 是否要钱）：

```bash
printf '{"video_models":"agnes-video-2.5-flash","text_models":"agnes-2.5-flash","spend":false,"pause":70}\n' \
  > production/AGNES_MODEL_PROBE_REQUEST
git add -A && git commit -m "probe" && git push
```

真提交（会消耗额度；免费档只花时间不花钱）：

```bash
printf '{"video_models":"agnes-video-2.5-flash","spend_models":"agnes-video-2.5-flash","spend":true,"spend_retries":11,"spend_retry_delay":180,"pause":70}\n' \
  > production/AGNES_MODEL_PROBE_REQUEST
git add -A && git commit -m "probe" && git push
```

`auto_video: true`（默认）会自动把 `/v1/models` 里所有 video 模型纳入探测，新上线的免费模型不会漏。
报告由工作流 commit 回本分支并覆盖 `production/agnes-probe/report.md` / `report.json`。
