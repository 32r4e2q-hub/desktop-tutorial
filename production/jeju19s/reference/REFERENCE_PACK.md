所有图都是生成式参考资产，不是真实案发照片或真实人物肖像。C 图用于人物外观锚定；
S 图用于环境；P 图用于道具。最终 Agnes 视频提示词仍由 `generate.py` 自动拼接
STYLE、逐字角色锚点、镜头描述和 NEGATIVE。

**生成顺序：** C → S → P。每张图片单独生成、逐张读回目视检查；不符合设计或有伪字/
多余肢体/不当内容时，针对同一编号重生成。仅经过检查并登记 SHA-256 的定稿可改为
`approved`。C 图为角色设定图（浅灰背景）；S/P 图统一 16:9 横图。

## 固定 ID 与视频提示词限制

- 角色锚点原文见 `build_story.py` 的 `CHARACTERS`，生成时 `generate.py` 会逐字插入，
  不要手动改写成真实人物特征。
- 每个 Agnes 镜头引用 1–5 张经审批的参考图；每张图在 `approvals.json` 中必须有准确文件路径与 SHA-256。
- 基础角色/场景/道具参考由 `revision.txt` 固定在不可变 commit（待本包全部 approved 后填写）。
- P01 与 P08 允许出现计时器数字 0:19；其余任何参考图与视频提示词均不得要求可读文字。
