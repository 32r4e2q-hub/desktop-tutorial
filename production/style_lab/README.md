# 参考风格实验室（style_lab）

**用途**：把用户上传的参考视频量成一份「风格档案」，据此给新片生成三组**逼真 3D 动画**的英文
`STYLE_PREFIX` 候选。

**什么时候用**：[`新题目开工手册.md`](../../新题目开工手册.md) 第 1 步之前——先定风格，再写提示词。
风格一旦定下来，45 个镜头的提示词都靠 `STYLE_PREFIX` 自动拼，改风格就是改这一个常量。

**它不是什么**：不剪片、不生成镜头、不产出成片。参考片**只用于分析**——一帧都不会进新片，
音轨也不克隆（手册第 1 步的事实边界）。

```
拖放上传 → 分片写盘 + SHA-256 → 抽 48 帧 → 逐帧统计（色调/影调/锐度/颗粒/景深/字幕带）
  → 运动采样 10 组 → 硬切粗检测 → 接触表 + reference_metrics.json + 风格档案.md + 三组候选
```

---

## 起服务

```bash
python3 -m pip install --break-system-packages -r production/style_lab/requirements.txt
python3 production/style_lab/app.py --port 8000
```

浏览器打开 <http://localhost:8000>（沙箱预览里是 `https://8000-<沙箱 id>.e2b.app`）：
把视频拖进虚线框，剩下的自己跑。180 秒 / 1080p 的片子大约 **50 秒**出结果，
其中 45 秒花在硬切检测（整段解码一遍）。

只要命令行、不要网页也行：

```bash
python3 production/style_lab/analyze.py --video ~/ref.mp4 \
    --out production/style_lab/runs/manual-001 --samples 48
```

沙箱里装不了系统 ffmpeg（非 root），`requirements.txt` 里的 `imageio-ffmpeg` 会带一份静态
ffmpeg；系统里已经有 ffmpeg 时优先用系统的。

## 指标口径与已知误差

| 指标 | 怎么算的 | 已知误差 |
|---|---|---|
| 影调 | 抽帧灰度均值 | 抽帧均匀覆盖，长片里罕见的极端段落可能漏掉 |
| 反差 | **帧内**灰度标准差（不是帧间） | 与「影调起伏」是两件事，别混着读 |
| 饱和 / 色温 | HSV 的 S 均值；`mean(R) − mean(B)` | 色温是相对值，受白平衡影响，不做绝对校准 |
| 主色 | 抽帧缩到 160px 后 k-means（k=6） | k-means 随机初始化已固定种子，结果可复现；小面积高饱和色会被吞掉 |
| 锐度 | 拉普拉斯方差 | 与分辨率相关；抽帧统一缩到 960 宽后再算，低清素材会如实偏「柔」 |
| 颗粒 | 原图减轻微高斯模糊后残差的标准差 | 分不清「真颗粒」和「强锐化」，两者都往高分走 |
| 景深 | 中心区 / 边缘区锐度比 | **暗角会骗过它**：边缘被压黑时方差天然为 0。这种帧直接剔除；可用帧不足时档案里写「判不了」 |
| 运动 | 10 组相隔 0.4 秒的帧对，灰度平均绝对差 | 分不清镜头运动和物体运动，只给一个总量级 |
| 节奏 | 画面差值硬切检测，阈值默认 0.24（沿用 `production/dahlia`） | **淡入淡出、机内运动、相似画面间的切换都会漏检或误检**，只作参考；新片不让改节奏，仍按 45 镜 × 4 秒网格走 |
| 底部字幕带 | 底部 12 % 的边缘密度 / 全画面边缘密度 | 只提示「疑似」，不判定内容 |

超过 15 分钟还没扫完的片子，切点检测会中断并在档案里标 `partial`，其余指标照常出。

## 结果怎么用

1. 网页上点开**接触表**逐格看一遍：确认这是你想要的那种片子，有没有混进别的东西；
2. 读**风格档案**里那张判定表，确认量出来的是你眼睛看到的；
3. 在**三组候选**里点「选定这组」——录取结果写进 `runs/<id>/chosen.json`；
4. 开工时把选中的 `style_prefix` 粘进 `production/<slug>/build_story.py` 的 `STYLE_PREFIX`，
   `NEGATIVE_PROMPT` **一起换**（旧的那份里有 `3D render look, plastic CGI`，留着就把 3D 画面自己否掉了，
   有测试守着：`production/tests/test_style_lab.py`）；
5. 把 `[本片场景：地点 + 年代 + 关键道具，开工时替换]` 换成本片的场景描述。

三组的差别**只**在画面定位与人物政策，调色 / 光线 / 颗粒词三份共用：

| id | 画面 | 人物 | 备注 |
|---|---|---|---|
| `photoreal_silhouette` | 实拍级 3D CGI | 只背影 / 剪影 / 手部 | 与手册护栏一致，推荐度最高 |
| `photoreal_faces` | 实拍级 3D CGI | 允许清晰的普通人脸 | **违反手册 PRINCIPLES**，采用前必须改护栏 |
| `cinematic_3d` | 3D 动画电影质感 | 只背影 / 剪影 / 手部 | 畸变最少、复审最省，写实数低一档 |

## 已跑过的校准样本

[`runs/示例-吉尔戈成片/`](runs/示例-吉尔戈成片/) 是用
[`交付/吉尔戈海滩_披萨盒里的凶手_三分钟_带声音.mp4`](../../交付/吉尔戈海滩_披萨盒里的凶手_三分钟_带声音.mp4)
跑出来的。那部片的风格是**已知**的（手绘 2D 动画纪录片、压暗的冷色调、胶片颗粒、45 镜 × 4 秒），
量出来是：整体偏暗 / 中低饱和 / 冷调 / 明显颗粒 / 中位镜头 3.65 秒（实际 4 秒网格）——
对得上，可以当这套指标的校准参照。

```bash
python3 -m pytest production/tests/test_style_lab.py -q     # 离线自检（8 个用例）
```
