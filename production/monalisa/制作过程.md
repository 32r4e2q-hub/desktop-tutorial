# 制作过程 · 蒙娜丽莎失窃案：一枚左手拇指印

按 `新题目开工手册.md` 的吉尔戈模式做：一个内容源（`build_story.py`）→ 配音 → 分句对齐 → 切点 →
Agnes 生成（runner）→ 逐镜复审 → 出片（runner）→ 逐字听检 → 发布。这里记录本片**和前两部不一样的地方**，
以及每一步的实测数字。

## 0. 需求

- 抖音横版 16:9、3 分钟、700–800 字口播的动画悬疑科普（无限科学《一口气看懂》式）：
  3 个爆款标题 / 一句话核心爆点 / 四列脚本表（时间轴 · 口播文案 · 画面描述 · 音效/备注）/
  0–5 秒黄金开头 → 背景 → 作案手法 → 高潮 → 结局 → 引导评论的金句。
- 按长岛（吉尔戈）那部的手册、工具链和画风做出真正的成片；逐帧检查畸变、音画同步、全面质检；
  生成时盯住 Agnes 进度，边生成边校验，有问题直接修。

## 1. 事实核查：简报里的「微观画布纤维」查无出处

简报的破案核心是「工作服上的白杨木纤维与画板比对」。查了 18 个来源（1913 年《纽约时报》《华盛顿晚星报》
原始报道、Hoobler《巴黎罪案》、中英意维基、Slate、LA Times、History.com、The Week、卫报档案……），
**没有任何一处提到纤维比对**。真实的「微观证据」有两样：

1. **玻璃罩上的左手拇指印**：贝蒂荣的部门有 75 万份档案、其中就有佩鲁贾 1908/1909 年的指纹，
   但分类只按右手拇指——不知道名字就查不到，他因此逍遥 28 个月；被捕后比对「每一处都吻合」。
2. **画板本身**：乌菲兹馆长波吉验画时，背面的卢浮宫印章与编号吻合，顶端那道裂缝和细密的龟裂网与照片吻合。

问了用户（ask_user），用户选「按史实改写（推荐）」：纤维情节整段不写，改用上面两样；
「死不认账的狡辩」改成他真实的「爱国」说辞，并用史实当场打脸（达芬奇 1516 年自己把画带去法国、
开价 50 万里拉、写信给父亲说要发大财）。标题和核心爆点跟着改。事实边界写在 `screenplay.md` 第一节，
每条都标了来源编号。

几处取舍：服刑「七个月」（意大利维基：上诉后七个月零八天；英文 Mona Lisa 条目写六个月，取多数来源）；
「趴在藏画的桌子上写完笔录」按「据记载」处理；「瓦尔菲耶诺侯爵策划」的传说（1932 年杂志文章，普遍认为是编造）不写。

## 2. 解说词：1037 → 899 → 875 字（含标点），变速 1.095 → 1.057

- 第一稿 1037 字，太长；压到 904、899 字后第一次 TTS：收紧停顿后 183.95 s，整体变速 1.095——
  离 render.py 的上限 1.10 太近（吉尔戈 1.048、spector 更低），听感会赶。
- 删改 N05/N06（裂纹一段去掉重复、结尾金句压短）后重录这两段：六段合计 **875 字（含标点）/ 773 字**，
  收紧后 **177.59 s，变速 1.057**。
- 配音 voice-00（用户在两个男声里试听选定）。六段 N01–N06 原始 191.94 s；`tighten_pauses.py`
  只剪静音、不动一个字 → 177.59 s。`audio/manifest.json` 里每段有文字 + SHA-256 收据，
  `render.py` 出片前逐段核对，文字或文件对不上就拒绝出片。

## 3. 分句对齐：第三种 DP 才对

切点和字幕都挂在「每个分句在配音里从哪一秒开始」上，所以这一步错了，后面全错。

| 做法 | 问题 | 例子 |
|---|---|---|
| spector 的分块 DP（一句话 = 连续几个语音块，块之间必须是停顿） | 一句话中间换了口气（句内停顿），前半块被判成「空」、时间被丢掉 → 下一句起点晚 1.1–1.5 s | N02 #9 算出 8.3 字/秒、N05 #16 9.0 字/秒——人念不出来 |
| 纯跨块 DP（边界只能落在停顿上） | 逗号处 TTS 没停（两句挤在一个语音块里）时分不开 | N05「细密的裂纹网，全部吻合」→ 2.83 / 11.36 字/秒 |
| **分组 DP（本片 `clause_times.align`）** | 一组 = 连续若干语音块 ↔ 连续若干分句：一句可以跨多块（句内换气），多句也可以共用一块（组内按字数比例切，再吸附到最近的能量谷） | 全部 76 句 4.2–7.3 字/秒 |

分组 DP 的两种情况都写进了离线测试（`production/tests/test_monalisa.py::GroupDPTest`，合成信号上
同时有句内换气和逗号不停顿，起点误差 < 0.08 s）。

事后三方印证（第 6 节）：波形逐帧看起音、whisper-medium 词级时间戳、分组 DP——三者一致到 ±0.29 s。

## 4. 切点：45 镜，按分句起点切，每镜 1.9–6.2 s，不慢放

- 默认切点 = 分句起点前 0.15 s（落在停顿里，画面先于声音一点点换）；`clause_times.py --check-cuts`
  检查每个切点都在分句起点前 0.35 s 的停顿窗内、每章第一刀在 0。
- 为了让太短的镜头长一点，少数切点在同一个停顿里挪（N01 S05 17.51、S06 19.6；N03 S16 5.92；N05 S31 6.8、S32 8.82）。
- 成片里 Agnes 镜头最短 1.90 s（S31）、最长 6.23 s（S45），全部 ≤ 6.7 s（手册：Agnes 素材 7 s，
  掐头去尾 0.12 s 后最多 6.8 s 可用，不许超过 1.33× 慢放）。
- 接受的妥协（另一种切法更糟）：S19 白杨木板信息卡同时盖住「可楼梯底下的门锁着」（单独切出来只有 1.66 s）；
  S07/S08 两张卡跨 N01/N02 背靠背；S28 从「警探上门问话时」切（从「更讽刺的是」切会到 7.17 s）；
  S40 从「这幅画是达芬奇…」切（4.87 s，而从「可历史当场打脸」切是 6.39 s、没有余量）；
  S30 开价卡从「联系佛罗伦萨的画商」切（只盖「开价」一句是 1.48 s）。

## 5. 逐帧畸变体检（本片新增 `clip_qa.py`）

沙箱连不上 Agnes 的 CDN（和吉尔戈、spector 一样），素材只能在 runner 上看。以前的 QA 是 2 fps 的
4×4 接触表（7 秒只看 14 帧）；这次每条素材生成后，runner 立刻对**全部 169 帧**算逐帧指标：

- 帧差 mad / 彩色直方图全变差 tv → 硬切（Agnes 偶尔在 7 秒里换场）；1–4 帧内回到原样的判为「闪帧」；
- 亮度离群 → 闪烁；黑帧；拉普拉斯方差骤降 → 糊；
- **光流补偿残差**：把后一帧按 Farneback 光流拉回前一帧，16×16 块的最大残差——正常运动能被光流解释，
  「融化 / 变形 / 凭空长出来」解释不了，出尖峰；
- 静止段：恢复运动那一帧跳一下的是**卡帧**（freeze），平滑起步的是运镜缓入/缓出（hold，只记录）；
- OpenCV Haar 正脸抽检（640×360 每 3 帧）：本片没有任何正脸，检出就必须人看（实际全是锦缎花纹、窗格、反光的误报）。

产出 `qa/Sxx-dense.jpg`（每 6 帧一张 + 逐帧曲线）、`qa/Sxx-flags.jpg`（每个事件的前后帧对照）、
`qa/Sxx.json`（逐帧数组）。在合成素材上埋了硬切 / 冻结 / 闪帧 / 局部变形 / 名画正脸，全部在正确的帧号上抓到
（冻结 f70–85、闪帧 f60–61、硬切 f87、变形 f100/f104、正脸 57/57 抽样帧），写进离线测试。
OpenCV 要钉 `<5`：OpenCV 5 删掉了 Haar `CascadeClassifier`（本地实测）。

`review_clips.py` 把逐帧数据和真实 EDL 时长合在一起，给每镜建议「素材里用哪一段」：
`render_segment` 从时间窗起点开始取成片需要的时长，而 Agnes 素材开头普遍有 0.3–1.2 s 的运镜缓入定格，
紧接硬切会像卡了一下——建议窗把起点挪到真正开始动的那一帧，同时避开自动标记的事件。

## 6. 出片前的配音 ASR 探针（本片新增 `asr_probe.py` + `monalisa-asr.yml`）

`verbatim_check.py` 只能听成片；可配音有没有吞字，最好在出片前就知道（重录只花一次 TTS）。
沙箱连不上任何 ASR 模型源，所以做成 marker 触发的 workflow：runner 转写六段配音（无 initial_prompt、
无 VAD、词级时间戳），报告 commit 回 `audio/asr-probe.json`。

起因：N01「而是一个意大利油漆工」对出来 7.3 字/秒，比全片均速快三成，怀疑 TTS 吞了字。结论：

- **没有吞字、没有多字**：六章听到的字数与剧本逐字相等（109/109、100/100……）。
- whisper-small 的 CER 0.07–0.16，差异几乎全是专名同音误听（卢浮宫→卢福宫、佩鲁贾→佩鲁甲、蒙娜丽莎→蒙纳利沙）。
  为把「念错」和「听写选错了同音字」分开，探针加了**无声调拼音音节错误率**：N02 CER 0.16、音节错误率 **0.0**。
- small 听成「游戏宫」（qī→xì）、N06 多出一个「他」——medium 复核：听为「油漆工」、没有多余的「他」。
  medium 六章 CER 0.008–0.056、音节错误率 0–2.6%。
- 分句起点：small 在 N06 整体比 DP 早 0.35–0.5 s；逐帧看波形，DP 的点正落在起音上（「我是爱国」实际 2.29 s
  起音，small 给 1.86 s，还在上一句里）；medium 各章与 DP 全部 ±0.29 s 内。
  → `render.py` 的字幕改为**分句 DP 优先**，whisper 词级时间只做交叉核对（差值写进 alignment-report）；
  → 成片逐字听检改用 **medium**（small 在 N02 上 0.15/0.16 随机摆动——whisper 温度回退有随机性，拿它当闸门等于掷硬币）。

## 7. 出片前的本地冒烟测试

38 条 testsrc2 假素材 + 按 `generate.request_hash` 算好的假 results.json，本地跑完整 `render.py`
（960×540、--skip-asr）：180.00 s / 5400 帧 / 30 fps / 立体声 AAC，混音 −21 dBFS、峰值 −1.6 dBFS，
只有最后 0.1 s（淡出尾）是静音。第一次冒烟字幕和标签全是豆腐块——本地替身字体家族名不对；
从 `notofonts/noto-cjk` 仓库用 GitHub git blob API 取回真正的 Noto Sans/Serif CJK SC（沙箱能连 api.github.com）
后重跑：片头标题、常驻标签、字幕、七张信息卡、片尾卡全部正确，字幕与口播逐句对上（例：25.5 s 屏上「文森佐·佩鲁贾，」，
计算值 25.14 s 起）。

这 9 条归纳成 6 条写提示词的规矩（已补进本片 `build_story.py` 各镜注释，下一个题目照做）：

1. **会重复出现的场景，颜色和陈设逐字复用已通过镜头的描述**（S17、S21 只写了 damask 没写颜色，就各画各的）。

5. **「脸藏在阴影里」+ 烟雾 = 从烟里凝出人形**（S23）；遮脸靠构图（低机位、画框上沿切掉），并写「谁也不出现、不消失」。
6. **没要求的运镜会自己加**（S20 固定机位却推近 → 露脸 + 颤帧）：写「completely locked-off, no camera movement at all」。

### 8.2 体检工具补一个漏洞：颤帧（`clip_qa.py` v2）

S20 首版开门后 5–7 s 画面「一帧一颤」，v1 的 7 项指标都没报——它不是尖峰，是 mad / flow 以 2 帧为周期
的锯齿（dense 图底部曲线一眼可见）。v2 加 `oscillation`：0.5 s 滑窗里去掉线性趋势，取「相邻差 × (−1)^k」
的**中位数**作为 2 帧周期振幅（单帧尖峰只影响 2 个差值，中位数≈0，不会误报起步 / 跳变）。
用已回来的 19 条标定：正常镜头最高 0.14，S20 首版 0.885、连续 34 帧；阈值 mad > 0.15 且 flow > 0.015、
连续 ≥ 6 帧。`review_clips.py` 对 runner 上旧版写的 JSON 直接用存下的逐帧数组按 v2 重算（不需要视频），
重生成那一轮起 runner 上就是 v2。另加 3 个测试（合成锯齿要报、平滑运镜 + 起止定格 + 单帧起步不报、
真实素材里只有 S20 首版）。

人脸：Haar 正脸检测到目前的命中全是锦缎花纹、窗格、画箱脚（框位逐个核过）；而 S20、S22 真正露出的
**侧脸 / 3/4 脸**它一个都没报——正脸级联本来就不认侧脸。所以「无 AI 人脸」这条只能靠人看 dense 图，
工具只负责把可疑帧挑出来。

### 8.5 S38–S41：两条闪回镜头的年代穿帮（规矩 7）

- S38（「我是爱国」）通过：办公桌后两名官员朝向镜头，但人小、整个逆着亮窗成剪影，无五官细节。
- **S39（1790 年代车队）、S40（1516 年达芬奇翻越阿尔卑斯）重生成**：路边 / 骡道边都立着路灯。
  全片 STYLE_PREFIX 为 1911–1914 年写了「gas lamps and early electric light」，模型把它带进了两个闪回镜头。
