# 蒙娜丽莎失窃案 · 逐镜视觉审查（生成与校验并行进行中）

审查依据（每镜三样，全部由 runner 在生成后立刻产出、commit 回分支）：

- `qa/Sxx-dense.jpg`：**每 6 帧一张**（0.25 s 一张，29 张 / 镜）+ 底部逐帧曲线（帧差 mad、直方图变化 tv、光流残差 morph、光流 flow、亮度、清晰度），红竖线 = 自动标记帧；
- `qa/Sxx-flags.jpg`：每个自动标记事件的「前一帧 | 这一帧」480×270 对照；
- `qa/Sxx.json`：ffprobe 规格 + `frame_qa`（**全部 169 帧**的逐帧指标、事件、Haar 正脸抽检）。

自动体检（`clip_qa.py`）只负责「哪里值得人看」；每一镜的结论都是人看完 dense + flags 两张图后写的。

红线：佩鲁贾与所有人物只给背影 / 剪影 / 手，不出现 AI 生成的正脸；《蒙娜丽莎》正面永远不画清楚；
画面里不出现可读文字或伪文字（手写涂画也要避开特写）；不中途换场；画风 = 吉尔戈同款
stylized 2D 手绘 graphic-novel（STYLE_PREFIX 与吉尔戈逐字同构，只换时代与地点名词）。

「成片用窗」= 素材里真正进片的那一段（`render.py` 的 WINDOWS；成片需要多长由 CUTS 决定，
`review_clips.py` 按起动帧 / 自动事件给建议，人看过后定）。Agnes 素材开头普遍有 0.3–1.2 s 的
运镜缓入定格，紧接硬切会像卡了一下，所以默认把起点挪到起动帧附近。
