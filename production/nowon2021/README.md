GitHub main 当前是 `fa1ddb8`，内置世田谷生成器为 text 模式，不能直接满足本片的图生视频。袴田案例在已完成的历史运行对应提交 `05574dbd8601150730651babd1fa9bbba012ad9e`（不在当前 main 树）上；其 30 镜生成模板使用 2.5 Flash 的 reference 模式。近期安城项目在提交 `e311fa74f3f0f850cf13b2d078ae1f1a7e9b8710` 中提供单线程创建、独立轮询/下载、任务回执及 12.1 秒最小创建间隔的排队方案。必须先适配、验证，再运行；不能假定这些历史结果证明本项目已提交。

官方 [Agnes Video 2.5 Flash](https://wiki.agnes-ai.com/en/docs/agnes-video-25-flash)：`model=agnes-video-2.5-flash`、`mode=reference`、`images` 是最多5个公网图片 URL；`seconds` 为字符串，`size=720P`，画幅16:9；1080p为后期放大。遵守用户的每分钟最多5次限制，POST与GET合计的间隔不少于12.1秒，尊重服务器 Retry-After；不换密钥或绕过队列。状态查询及服务端实际并发/额度限制也须遵守。

## 视频请求长度

脚本保留原稿5–7秒的最终剪辑时长。历史袴田项目有名义7秒素材只返回约6.592秒的记录，故本项目离线请求计划按镜头时长加1秒申请源片，最终从连续运动的源片裁切到5–7秒；实际源片是否足长须生成后解码核实，不能承诺剪辑已完成。
