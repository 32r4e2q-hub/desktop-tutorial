# Vidu key 实测结论（2026-10-17）

## 一句话

**仓库里确实有 Vidu key，它是有效的，但账户余额是 0 —— 生成不了，也谈不上免费。**
**用户后来追加的国内站 key 同样有效、同样零余额（见第 4 节）。两把 key 都过不了"免费生成"这一关。**

## 证据

探针：`production/vidu_probe.py`，跑在 GitHub Actions（沙箱连不上外网 API，GitHub secret 名字也读不到）。
报告原文：`report.json` / `report.md`（每轮覆盖）。

### 1. Key 存在，且只认国际站

| 项 | 值 |
|---|---|
| secret 名 | `VIDU_API_KEY` |
| 长度 / 末 4 位 | 56 / `ZS1N`（只记指纹，不记原文） |
| `https://api.vidu.cn/ent/v2/credits` | **HTTP 401** `Unauthorized` |
| `https://api.vidu.com/ent/v2/credits` | **HTTP 200** |

所以这把 key 是**国际站（`api.vidu.com`）**的，国内站用不了。这一点很关键：
后续所有请求都必须打 `api.vidu.com`，并且鉴权头是 `Authorization: Token <key>`（不是 `Bearer`）。

### 2. 账户余额：0

`GET /ent/v2/credits` 的原文：

```json
{"packages":[],"remains":[],"queue_count":0,"general_remains":[],"exclusive_remains":[]}
```

四个数组全空 = **没有任何积分包、没有任何赠送额度、队列里 0 个任务**。

### 3. 真提交一条最小任务，被明确拒绝

按 `viduq1/viduq2/viduq3-turbo × 540p/720p` 逐个试（参数不合法不扣费）：

| 模型 | 分辨率 | 结果 |
|---|---|---|
| `viduq1` | 540p | 400 `FieldInvalid: resolution is invalid`（国际站不认这个参数组合） |
| `viduq1` | 720p | 400 `FieldInvalid: resolution is invalid` |
| `viduq2` | 720p | **400 `CreditInsufficient: insufficient credits`** ← 参数终于对了，卡在钱上 |

`CreditInsufficient` 是决定性证据：**不是 key 错、不是参数错、不是网络问题，就是没积分。**

### 4. 用户直给的国内站 key：有效，但也零余额

为排除"国际站 key 恰好没钱、国内站账号有钱"的可能，用户另外提供了一把国内站 key，
存入 GitHub Actions secret `VIDU_CN_API_KEY`（未写入仓库任何文件，只记指纹）：

| 项 | 值 |
|---|---|
| secret 名 | `VIDU_CN_API_KEY` |
| 长度 / 末 4 位 | 56 / `4nwG` |
| `https://api.vidu.cn/ent/v2/credits` | **HTTP 200** ← 国内站认这把 key |
| 积分原文 | `{"packages":[],"remains":[],"queue_count":0,"general_remains":[],"exclusive_remains":[]}` |
| `viduq2` + 720p 真提交 | **400 `CreditInsufficient: insufficient credits`** |

结论一致：**key 是真的、能登录，但账户里没有积分**。国内站与国际站是两个独立账号，
两边都没有可用余额，所以"换一把 key 就能免费跑"的假设不成立。

补充：`api.vidu.cn` 同样不接受国际站那把 `VIDU_API_KEY`（HTTP 401），两站 key 不互通。

## 为什么"免费"这条路走不通

- Vidu 网页版/App 的「每月 80 积分、约 20 条 4 秒视频」是**账号端**的免费额度，**不适用于 API**。
- API 的「错峰模式（off-peak）」是**半价**，不是免费，而且同样要消耗积分。
- 因此这把 key 在充积分之前，一秒钟视频都生成不出来。

## 要花多少钱（如果决定充值）

按官方积分单价约 `$0.0035/积分`、本片 30 镜 × 6 秒 = 180 秒估算：

| 档位 | 积分/秒 | 180 秒需要 | 约合美元 |
|---|---|---|---|
| `viduq3-turbo` 540p | 8 | 1,440 积分 | ≈ $5.0 |
| `viduq3-turbo` 720p | 12 | 2,160 积分 | ≈ $7.6 |
| `viduq3-turbo` 720p 错峰 | 6 | 1,080 积分 | ≈ $3.8 |
| `viduq3-pro` 720p | 30 | 5,400 积分 | ≈ $18.9 |

（单价与积分率以官方账单为准；上面只是用来判断量级的估算。）

## 怎么复跑

```bash
# 只查积分（零成本）
printf '{"spend":false,"host":"https://api.vidu.com"}\n' > production/VIDU_PROBE_REQUEST
git add -A && git commit -m "vidu probe" && git push

# 真提交一条最小任务（有积分才会扣）
printf '{"spend":true,"host":"https://api.vidu.com"}\n' > production/VIDU_PROBE_REQUEST
```

已探过的 secret 名：`VIDU_API_KEY`、`VIDU_KEY`、`VIDU_TOKEN`、`VIDU_APIKEY`、`VIDU_CN_API_KEY`、`VIDU_AI_API_KEY`。
