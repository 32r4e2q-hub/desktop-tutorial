## 限流原因与修复

Agnes 官方说明，免费/默认密钥的视频模型限制为 **1 RPM**，即每分钟一个模型请求。[1](https://agnes-ai.com/en/docs/tokenplan)

过去允许两个生成任务并行，但没有单独限制“创建请求”的频率，短时间内提交请求触发了429。

新代码已改为：

- 所有创建请求共享队列，至少间隔 **75秒**。
- 最多两个任务在途，不等于同时发起两个新请求。
- 收到429后保留服务端 `Retry-After`，两个工作线程共同退避；不立即跳到下一个镜头。
- 状态查询间隔改为25秒；查询若也被限流，同样延后。
- 不轮换密钥绕过限制，不自动升级套餐，不自动换成其他视频模型。
- 已完成且请求/文件摘要匹配的素材直接复用；已提交的任务按原编号恢复，不盲目新建。
- 生成阶段最多使用85分钟，预留剪辑时间。遇到持续限制会保存状态退出，不伪报成功。
