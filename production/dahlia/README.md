## 制作与复用

- `story.json`、`screenplay.md`：叙事素材计划、正负向提示词、事实边界及来源。
- `audio/`：用户选定声音的录音与文本/文件摘要。
- `assets/`：档案肖像及来源说明。
- `qa/`、`visual-review.json`：原素材的抽样检查图与记录。
- `delivery/`：实际成片的技术报告、字幕、时间线、抽样图及复核说明。
- `generate.py`、`throttle.py`：只调用指定Agnes模型，75秒共享创建间隔、Retry-After退避、任务编号恢复和缓存复用。
- `render.py`、`align_audio.py`：云端剪辑、受控图解、ASR辅助字幕对齐及明确标注的停顿回退。

大视频使用Actions artifact，不提交到Git。仓库只保存必要的输入、小尺寸检查图和制作元数据。
