# 西口彰事件：78天的逃亡

## 现状（未交付成片）

- 30 镜、180 秒、16:9 的分镜计划与逐镜旁白：`story.json`、`screenplay.md`。每条镜头 5–7 秒。
- `reference/` 有男主、寺院、寺院人物和封面背景四张 AI 示意图。都不是现实人物照片或真实影像。生成采用文字模式，参考图**不会作为模型输入**，仅供人工审校；角色一致性尚未验证。
- `audio/` 仅 S02–S10 九条旁白。S01 因 TTS 内容审核未生成，S11–S30 尚未生成；必须补齐、实测，再制作字幕。旁白的文本长度不等于实测语音时长，当前尚未完成声画匹配。
- `generate.py` 沿用世田谷项目的 Agnes Video 2.5 Flash 720P、61秒节流、源片校验、断点记录和真实视频硬要求。当前**只支持素材生成**，还不能合成成片，不会以静态参考图充数。项目专属配乐、音效、字幕、转场、封面标题和合成/质检尚待实现。
- `.github/workflows/nishiguchi1963-gen.yml` 是当前分支专用的运动镜头生成流程：先跑 S01 再跑其余镜头。执行需要 GitHub Actions 和仓库的 `AGNES_API_KEY` secret；无法从本地验证 secret 是否存在。结果须逐镜检查，不可把解码成功当作视觉审校通过。源视频作为 Actions 工件保存七天；恢复时生成器会尝试从已有回执重新下载，需留意素材 URL 有效期。

## 事实边界与修订

1. 1963-10-18 福冈两人遇害，警方通缉西口；11月滨松旅馆经营者母女遇害；12月东京律师遇害，合计五名遇害者。80万日元为公开资料所述诈骗金额的近似值。
2. 原稿称「12月下旬」拜访古川；多个资料记为 **1964-01-02**，1月3日被捕，已改正。
3. 古川女儿年龄资料出现10岁和11岁两种说法，本片写「小学五年级女孩」，避免争议。她先认出通缉照片，家人进一步核实并通报；不将通报功劳单独归给警方或某一名家人。初期父亲不相信有报道支持。
4. 10月18日至次年1月3日**相隔77天，首尾两日均计入为78天**；公开报道亦有77天的写法。
5. 末尾广传的「十二万警察不如少女的眼睛」数量及发言人来源有歧异（也有13万人及警察官员的版本），为避免误引，不直接归为警察厅长官原话。
6. 空卡车、地上鞋子与灯光熄灭等是安全、非血腥的**象征性重构**，并非宣称镜头中物件是当时警方确认的证物或具体发生的情节。避免将受害者与幼童置于危险画面。
