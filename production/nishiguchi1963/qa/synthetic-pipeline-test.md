# 合成和客观质检流程的合成夹具测试

这不是影片成片，不是 Agnes 生成视频，也不代表视觉审核通过。仅在 `work/` 中使用动态测试图案，刻意在该测试内部关闭源片回执校验以模拟素材；正式 `render.py` 的哈希与来源验证没有更改。

- 30镜的归一化、后半段叠化、字幕渲染与30条实际旁白混音：完成。
- 测试输出：1920×1080、24fps、4320帧、180秒、H.264 + AAC 48kHz双声道。
- 合成夹具的客观质检结果：字幕30条，与测试时间轴的旁白文本一致；格式、帧数、时长、黑帧、冻结及声量硬闸门通过。
- 与真实视频无关：所有实际运动镜头的人物畸变、伪文字、年代、内容安全和视觉一致性仍需逐镜审看；当前四镜重做尚未全部完成。
