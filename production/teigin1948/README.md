# 帝银事件：一杯“预防药”

三分钟抖音横屏悬疑短片制作包（16:9、1920×1080、24fps、180秒、29个连续3D动画镜头）。本目录按 `production/setagaya2000` 分支模板整理：先定角色/场景参考，再按镜头生成真实运动视频，之后配音、字幕、音效/BGM与剪辑。已从用户给出的 `arena/fed820f6-desktop-tutorial` 分支检查模板实现，角色与场景参考图已定稿，29镜旁白与S01–S29逐镜配音已完成；本地预混音实测180秒、RMS −21.73dBFS、峰值 −1.5dBFS、BGM相对旁白约−20.07dB。Agnes动态镜头生成已由GitHub Actions运行中；视频素材齐备后将自动进入已排队的渲染/QC流程。

## 开工顺序
1. `reference-prompts.md`：先生成并审核角色与场景定稿参考图；角色均为风格化虚构形象，不还原真实肖像。
2. `story.json`：逐镜提示词已自动包含全局【STYLE】、涉及人物时对应角色设定、末尾【NEGATIVE】。S01–S29 时长合计180秒，镜头均要求连续真实动画运动；不是静态图推拉。按每镜4–9秒生成视频，严格使用镜头编号命名。
3. 按`screenplay.md`录制中文旁白并生成逐句同步字幕。建议男声沉稳叙述，平均约3.7字/秒；“一分钟后”“死刑从未执行”留约0.5秒停顿。关键词白字黑边，金色放大强调，字幕置底部安全区。
4. 按`edit-plan.md`顺序拼接镜头，加入音效、BGM、转场和封面；混音BGM低于旁白约18dB，输出1920×1080、24fps、180秒。

## 目录文件
- `reference-prompts.md`：角色与场景参考图提示词、统一性检查表。
- `story.json`：可供生成/剪辑流水线读取的元数据及29条完整画面提示词。
- `screenplay.md`：旁白、字幕重点与逐镜时间轴。
- `edit-plan.md`：配音、音效、音乐、封面、平台发布要求。
