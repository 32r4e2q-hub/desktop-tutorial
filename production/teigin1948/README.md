# 帝银事件：一杯“预防药”

三分钟横版悬疑短片制作包：16:9、1920×1080、24fps、180秒、29个连续运动镜头。视频镜头保持不变，此次重点是让每段中文解说贴合对应画面时长，并保证每个完整句子单独成条字幕；S29最后一秒保留片尾静音。调整断句以保持语义连贯。新母版正在渲染并执行最终QC，QC通过后再标记交付完成。封面保留十六只杯子及末杯红点设计。

本轮旁白混音预检：180秒；RMS −20.75 dBFS；峰值 −1.50 dBFS；BGM低于旁白约19.87 dB。29条旁白覆盖对应片段的86.12%–97.29%（S29保留最后一秒静音），每条字幕对应一个完整句子。重新渲染后再核对成片QC报告。

## 制作规格

- 29镜、9章，逐镜独立真实运动视频，不以静态图推拉代替。
- 角色和场景使用风格化非肖像参考图；每镜提示词采用统一风格及负面约束。
- 中文男声旁白逐镜同步；关键词金色强调；字幕位于底部安全区。
- 原创悬疑音乐、音效与段落转场；末秒静音收尾。
- 封面指定标题“十六个杯子”，画面为16只杯子一字排开，红点落在末杯。

## 内容与事实口径

短片以间接物件和环境表现受害经过，不展示遗体、伤口或血腥。关于731部队涉案的说法明确标记为未经证实的传闻，不作为事实。平泽贞通1950年被东京地方法院一审判处死刑，1955年最高法院维持判决；旁白保留“判决”“否认”及争议背景，不断言其为真凶。

## 工作流

1. 先核对 `reference/` 定稿图，再按 `story.json` 生成真实动态视频。
2. 逐镜旁白及字幕文案见 `screenplay.md`；音频测量、混音和 SRT 校验由 `build_audio.py` 与 `render.py` 自动完成。
3. `qc.py` 检查容器、时长、黑帧、冻结、闪变、音频电平、字幕、封面尺寸，并导出原分辨率抽帧与联系表。
4. `qa/human-review.json` 记录逐镜抽帧审看范围；技术报告会同时注明人工抽帧与全片运动采样的边界。
