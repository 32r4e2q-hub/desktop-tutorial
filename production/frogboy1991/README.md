# 青蛙少年失踪案：一个没有回家的春天

三分钟横版（16:9 · 1920×1080 · 30 fps · 180 秒）中文悬疑解说短片，抖音横屏观看版本。

- 不展示遗体、遗骸、血腥或作案过程；遗骸发现镜头只见警戒线、勘查人员背影与荒地。
- 五名儿童不以可辨识面容出现，名字只在字幕与信息卡里以文字出现。
- 不做任何真实人物的肖像还原；大人角色均为 AI 生成的匿名人物。
- 案件未破，片中不做推测性指认。
