## 1. 题目与用户的三条硬要求

- 用户上传的 40 镜文案稿（`抖音文案/20261008-075847_粘贴的文案_20261008-075847.txt`）给出叙事骨架与反转设计：
  先让观众相信「一个杀人犯改造成功、成了作家」，到中段才第一次出现新的命案。
- 用户的三条硬要求：**3D 动画（不是图片视频）**、**人物要丰富（不要一路场景空镜）**、
  **可以先出图把脸固定住**（不同人物不同脸、同一人物同一张脸）。
- 落实：**6 个露脸角色 · 19 个露脸镜头**（上一部座间案是 4 角色 / 8 镜）；38 个 Agnes 镜头里 32 镜画面有人，
  纯空镜只有 6 镜；**6 张定妆照**（每个角色的首次露脸镜头用图生视频首帧把脸钉住）。
- 事实核查：9 条公开来源（维基、卫报书摘、Murderpedia、Jim Shelley、德语维基、纽约时报讣闻、
  Serial Killer Calendar、Skeleton Key Chronicles、IMDb 新闻页），逐句对照写进 [`史实核对.md`](史实核对.md)。

## 3. 内容与闸门

```bash
python3 production/unterweger/build_story.py                                    # 唯一内容源 → story.json
python3 production/face_cast.py check-prompts --project production/unterweger   # 露脸静态闸门（PASS）
python3 production/unterweger/generate.py --validate                            # 计划与配音闸门（VALID）
python3 production/unterweger/clause_times.py --check-cuts                      # 切点闸门（全绿）
```

- 45 镜 = 38 agnes + 7 信息卡（S02 名片 / S11 第一条人命 / S18 改造成功的样本 / S24 假释之后 /
  S31 并案 / S37 被捕 / S40 判决）；每镜只用一次，`make_edl` 有断言。
- 解说 6 段 794 字（含标点）；TTS 原始 179.80 s → `tighten_pauses.py` 收紧到 155.30 s（只剪静音），
  可用窗口 168 s，实际变速比 0.924。
- `CUTS` 用新增的 `tools/retime_cuts.py` 按分句起点 − 0.15 s 重对（脚手架原来是 4 秒均匀网格），
  `clause_times.py --check-cuts` 全绿；成片最长一段 5.93 s（< 6.3 s 上限，Agnes 素材只有 7 s）。
- 片头卡第一行按上一部的教训拆成两行（`杰克·翁特维格 / 最成功的一次伪装 · 一九七四至一九九四 奥地利`），
  卡片排字过 `test_card_typography.py`，并人工看了片头/信息卡/片尾卡的排字预览，无裁字。

## 4. 露脸模式（本片重点）

- 六个虚构匿名角色：**C1 作家（本案核心人物）**、**C2 女记者（电视台）**、**C3 出版社老编辑**、
  **C4 维也纳刑警**、**C5 洛杉矶女警探**、**C6 夜场女招待**；每个角色一条 face token、一个固定 seed、
  一张定妆照。**不做任何真实人物的肖像还原**——主角不是翁特维格本人的脸。
- 同一张脸跨镜稳定靠三件事叠加（沿用 zama2017 的接线，`generate.py` 从那部移植后只换项目名/分支/片名）：
  1. 提示词里**逐字节**照抄该角色的 face token（`{C1}`…`{C6}` 占位符从 `cast.json` 注入）；
  2. 单角色镜头用**角色 seed**（`shot_seed()`：C1=19900523 出狱日 / C2=19910611 抵洛杉矶 /
     C3=19830915 出书年 / C4=19920213 逮捕令 / C5=19910624 / C6=19901020 首案月）；
  3. 六个角色的**首次露脸镜头（S04 / S07 / S12 / S21 / S22 / S25）用定妆照做图生视频首帧**。
- 两道闸门：`check-prompts`（生成前，已 PASS：6 角色 / 19 镜）＋ `check-frames`（接进 `*-visual-qc.yml`，出片后跑）。
