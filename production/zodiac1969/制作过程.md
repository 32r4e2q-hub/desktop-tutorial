# 十二宫杀手：仍未说出的名字 · 制作过程

slug `zodiac1969`，分支 `arena/01a08a23-desktop-tutorial`，2026-09-10 开工。
三分钟横屏中文解说 · 1920×1080 / 30fps / 180 秒。
流水线按《新题目开工手册.md》走；参考项目 `production/dahlia/` 只读、未动（`test_reference_project_is_untouched` 守着）。

## 选题与事实核查

- 题材：旧金山湾区「十二宫杀手」（Zodiac）悬案——美国最著名的未侦破连环案之一。
- 事实全部来自公开来源，逐条列在 `story.json` 的 `sources`（Wikipedia / BBC / History.com / USC 教学页）。
- 关键数字口径：**警方确认 5 死 2 伤（七名受害者）**；凶手自称数字（1971 年信 17 人、1974 年最后一封信「Me = 37, SFPD = 0」）**单独表述**，不与确认数字混写。
- 红线：不指认嫌疑人；不写血腥与侵害过程（袭击一律画外）；AI 画面不出现可辨认的真实人物（全部背影/剪影/无面孔泛化形象）；姓名、日期、译文全部后期字幕，不交给视频模型拼写。
- 没有使用 archive 镜头：本片不需要任何真实人物影像（受害者、嫌疑人、破译者都不出镜），故 `story.json` 无 `archive` 镜头；`render.py` 的 `archive_image()` 保留但不被调用，`assets/` 不建。参考片用档案照是因为要展示真实人物，本片的可核查锚点放在 6 张信息卡（日期、数字、译文）上。

## 分镜

30 镜 = 24 条 Agnes 生成 + 6 张信息卡（S03/S08/S12/S18/S20/S22），6 章 × 30 秒。
- S12 卡画了十字圆圈符号（本片主题符号，PIL 矢量绘制）。
- 片尾卡：`十二宫杀手 / 五起确认的死亡 · 三十七个声称的数字 / 那个名字，五十年后仍未被说出`。

- 工作流：`.github/workflows/zodiac1969-agnes-autotrigger.yml`（push 触发，paths 过滤 `.agnes-trigger`）。

## 踩过的坑（本片实际发生）

1. **沙箱网络**：只有 pypi / github（含 codeload）可达；apt 源、Wikimedia、johnvansickle、agnes 平台都不可达。
   - ffmpeg 用 `pip imageio-ffmpeg` 的静态二进制（7.0.2）软链到 /usr/local/bin；ffprobe 缺失时 `media.probe` 走 PyAV 回退；
   - 本地预检中文字体从 GitHub 仓库 `zhongshukeji/Noto-Sans-SC` 取 OTF 放到 `.cache/fonts/`（不进 Git，.gitignore 外但 .cache 已忽略）。
2. **archive 图拿不到**：Z408 密码原件照片在 Wikimedia（沙箱不可达），GitHub 上搜不到可用的原始影像。
   决策：砍掉 archive 镜头（本片没有真实人物出镜需求），改为 24 agnes + 6 graphic，可核查锚点全部落在信息卡文字上。
3. **workflow_dispatch 403**：见第 6 节；用 push 触发器 + paths 过滤解决，生成/出片/听检三条链路全部留在本分支内。
4. **生成 run 与本地 push 竞争**：生成工作流 checkpoint 推分支会让本地 push 被拒（non-fast-forward）；`git pull --rebase` 后再推即可，属预期行为。

## 已知限制（继承参考项目）

- 视觉审片：构图 / 字幕错字 / AI 畸变仍需人看对照表与抽样帧；
- 逐字听检：ASR 自身也会错字，超阈值段落要人耳裁决；
- 字幕对轨：ASR 覆盖不足的段落回退停顿估算，覆盖率写进 `delivery/alignment-report.json`；
- Actions artifact 在沙箱里下载不到，成片一律靠 commit 回分支取。
