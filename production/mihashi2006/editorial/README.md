## 落地到本片的四条硬规则

1. **假对比一律不写**。禁用「不是 X，而是 Y」「你以为 X，其实 Y」「不只是 X，更是 Y」「X 只是表面，Y 才是关键」「这不叫 X，这叫 Y」。
   例外只有一个：纠正可核实的事实（例如「日媒写年收入一亿五千万，另一批写一千万以上，本片不写年收入」这种口径澄清），且必须在 `FACT_CHECK.md` 里有对应条目。
2. **空转词删掉**：本质上、归根结底、真正的核心是、这背后反映的是、值得注意的是、众所周知、不难看出、令人唏嘘。
   删完如果这句没有信息，就补一个具体动作、时间、地点或后果；补不出来就整句删。
3. **不拔高、不总结人生**。片尾只留三件事：一个具体事实、一个真问题、系列落版。不写「愿我们都能……」「希望这样的悲剧不再发生」。
4. **具体优先**。每条解说里至少有一个可核实的专名、时间、地点或物件（代代木公园旁的公寓、电梯、行李箱、芹泽……按 FACT_CHECK 口径写）。
   禁止「心里很痛」「令人震惊」「让人不寒而栗」这类只有情绪没有对象的句子。

## 检查流程

```bash
# 1. 抽出全片解说，逐条过机械预检
python3 production/mihashi2006/editorial/check_narration.py
# 2. 命中硬拦截（假对比）必须改；软提醒逐条判断
```

`check_narration.py` 会把 `story.json` 的 30 条解说、钩子、金色注释、封面两行字、发布文案正文拼成一份待检文本，
调用 `ai_tell_linter.py`，并把结果写进 `production/mihashi2006/qa/deai-report.md`。
机械预检只说明「没有踩到已知句式」，最后一关是人念一遍：这句话像不像一个中国人对着镜头说话。
