# 用户最新要求：严格检验，不合格重做

本要求覆盖“素材齐备即可作为终版交付”的任何理解。生成完毕、工作流成功、收据数量齐备，都不是视觉合格或终版签收。

## 1. 逐镜复审（38动态片段＋7信息卡）

- 动态片段须逐段播放并查看接触表、必要时逐帧查看；不能只看文件存在、时长、SHA或首帧。
- 检查真实镜内运动；不能用静态图推拉、冻结或过度重复往返替代动态素材。
- 同一角色跨镜同脸；C1日常/波戈为同一虚构成年演员。面容token、seed和模型相似度分数均不能单独证明同脸。
- 检查脸、手、肢体、物体变形，突变、闪烁、意外换场，年代、服饰、场景和视线/运动方向一致性。
- 检查画面是否服务对应旁白；技术指标合格但语义不符也必须整改。
- 少年只背影/剪影；无遗骸、血腥、侵害或执行过程；虚构演员不冒充真实人物容貌。
- 信息卡逐张检查事实、错别字、可读性、安全边界和排字溢出；标题、字幕和卡片均由后期排字。

每个结论须绑定实际片段SHA，记录发现的问题、帧号/时间点、复审依据。未检查的镜头保持pending，不默认pass。

## 2. 返工闭环

- 仅重做不合格镜头，保留合格素材。修改提示词须遵守内容审核，不混淆词语或规避1301。
- 同提示词真重抽须使用模板的force选项，例如{"only":"Sxx","force":true,"ref_image":false}，只写only可能复用旧收据。
- 旧收据归档，只有新素材完成下载/解码、SHA记录及实际复审后，才能作为替换版本。
- 重生成后旧视觉签收自动视为失效；不能把原片段检查结果套在新SHA上。
- 更新素材后重核取用窗、CUTS与真实旁白分句停顿；不能因素材时长不同而截字、复用镜头或补静态图。
- 认证、额度、参数等非暂时故障须明确报告并修正；不采用付费模型兜底，不声称无限循环能解决所有故障。现有40轮预算保持有效。

## 3. 成片复检

- 180秒、1920×1080、30fps，5400/5400帧完整解码；非计划黑帧、非信息卡冻结和意外闪切必须处理。
- 按实际交付MP4做逐字听检、字幕同步和音轨实测，不能借用配音预混报告代替成片测量。
- 白字黑描边、金色放大关键词、底部安全区；指定停顿、五次0.3秒章间黑场、末秒静音均在成片上核验。
- BGM约低于旁白18dB，不盖人声；检查章节间音量、爆音、截断、音效与动作对应关系。
- 脸/手/时序自动审计仅是分诊；所有候选和报警必须逐项复核，不能以脚本成功替代视觉判断。
- 通篇连续观看，核查叙事衔接、节奏、信息卡、封面、发布文案及来源一致性；修订后重新绑定最终影片SHA。

## 4. 交付口径

自动渲染可以产生用于复核的初剪，自动听检和全帧检查可以先运行，但它们不自动授予终版资格。
未关闭问题、未完成实际视觉复核/手册要求的人工语义签收的文件，只能标为“待审初剪”。
不承诺无法客观证明的绝对完美；以以上可检查标准持续返工，未通过不宣称终版。
