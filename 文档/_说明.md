# 文档上传区

这个文件夹是**通用文档的上传落地点**：网页上传区收到的每一份 txt 都会原样存在这里，
文件名自动加时间戳（如 `20261006-120000_我的文档.txt`），重名不覆盖，历史稿都留着。

> 和 `抖音文案/` 的区别：那边是做抖音视频的口播文案专用，这边是放任何通用文档
> （资料、稿子、笔记、大纲……）的，两个上传区互相独立。

## 怎么用

网页上传工具启动后，把 txt 拖进上传区即可：

```bash
python3 电影解说工具包/upload_doc_server.py 8802
```

上传完成后，直接回到对话里说一句「文档传好了」，我就能读到 `文档/` 里的最新文件。

## 说明

* 只收**纯文本**：`.txt .md .json .csv .srt .vtt .log .yml .yaml`，单个最大 20 MB。
* 编码自动识别（UTF-8 / UTF-8 BOM / GBK·GB18030 / Big5 / UTF-16），统一存成 UTF-8，
  Windows 记事本存的文件不会乱码。
* Word / PDF 请先「另存为 → 纯文本 txt」，或直接把文字粘到上传区第二个输入框。
* `上传记录.jsonl` 是每次上传的时间、字数、行数、原编码记录，删掉不影响使用。
