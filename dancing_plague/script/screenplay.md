# 《1518：没有音乐的舞蹈》—— 斯特拉斯堡跳舞瘟疫

## 一、主题 / 故事 / 视觉风格

**主题**：1518 年 7 月，神圣罗马帝国自由城市斯特拉斯堡爆发的“跳舞瘟疫”。从一个女人在街头独自起舞开始，一个月内蔓延到近四百人，
当局先以“让他们继续跳”应对，再到禁止音乐、把病人送往圣维特圣坛；最后回到现代历史学家的两种解释（麦角中毒 vs 集体心因性疾病）。

**故事结构（三幕）**
1. 起（0:00–0:40）：夏夜冷开场 → 标题 → 特罗菲亚起舞 → 时间流逝，人数暴增。
2. 承（0:40–1:25）：广场群舞、昏厥 → 市议会与医生的“热血”诊断 → 木台与乐师，事态失控 → 禁乐，马车送往圣维特圣坛。
3. 转合（1:25–2:15）：麦角假说的提出与反驳 → 沃勒的“集体心因性疾病”与恐惧的传染 → 回到黎明空巷，留白结尾。

**视觉风格**：电影级 2D/2.5D 动画纪录片。
- 画幅 16:9 内嵌 2.39:1 遮幅；24 fps；1280×720。
- 低饱和的中世纪调色：夜戏冷蓝青，火光戏暖橙，麦田戏土黄，回忆/解释段落偏灰绿。
- 角色为强剪影、写实比例的骨骼绑定 2D 人偶（走路、舞蹈、倒地、跪拜、写字等循环），近景有面部表情（眉、眼、口）变化。
- 场景为多层视差（天空 / 远景教堂 / 中景房屋 / 近景房屋 / 透视地面），摄像机推拉、横移、跟随、轻微手持抖动。
- 环境永远在动：雨、雪、烟、火星、雾、尘埃、摇晃的挂灯、风中的黑麦、闪烁的烛火与窗光。
- 后期：胶片颗粒、暗角、色彩分级、轻微光晕。

## 四、技术方案

- 引擎：`engine/`（Python 3.11 + numpy + OpenCV + Pillow），逐帧程序化渲染，多进程分段编码。
- 角色：`engine/characters.py` 前向运动学骨骼（骨盆/脊柱/头/上臂/前臂/大腿/小腿/脚），动作循环参数化并带随机相位，保证群体不重复。
- 摄像机：每个镜头定义关键帧（位置 / 缩放 / 滚转），缓入缓出插值，各层按深度做视差，地面用单应变换做真实透视滚动。
- 特效：`engine/fx.py` 雨、雪、烟、火星、尘埃、多倍频值噪声雾、径向光晕、闪烁函数、暗角、颗粒。
- 音频：`engine/audio.py` 合成雨/风/人群/鼓/笛/钟/心跳/脚步与配乐 drone，与旁白混音并做自动闪避（ducking）。
- 合成：静态 ffmpeg（libx264 CRF 18, yuv420p, AAC 192k, faststart）。
- 质检：`engine/check.py` 全片解码、黑场/冻结帧检测、音画时长与旁白起点对齐、响度与峰值检查。
