# 开膛手杰克 · 三分钟 AI 写实电影解说动画
## 高阶提示词体系（v1.0）

> 制作方法：**AI 关键帧 → 2.5D 运镜引擎（Ken Burns + 粒子 + 电影调色）→ 溶解转场 → 中文男声旁白 + 合成氛围音 → 底部描边字幕 → H.264 1080×1920 30fps 压制 → 自动 QC**
> 本文件既是「分镜剧本 + 提示词库」，也是给 Agnes / 豆包 / ChatGPT / 文心千帆 等任意文生视频、图生视频、文生图模型的**通用提示词适配层**。
> 历史事实全部经过逻辑审查，见第 6 节《逻辑审查规则》；每个镜头的时间、地点、人物均按 1888 年真实案件档案校准。

## 2. 风格锚定（从参考视频逐帧提取）

参考视频《磷》（16:31）逐帧分析结论，作为本项目**唯一**风格基准：

**A. 视觉基因**
- 光：**琥珀煤气灯 / 烛光 / 炉火**为暖主光；**石板蓝 / 雾灰**冷环境光补暗部；明暗对比强（伦勃朗式布光）
- 色：棕褐（raw umber）基调 + 琥珀高光 + 蓝灰暗部；整体饱和度中等偏低，不艳
- 质感：**35mm 胶片颗粒**、边缘暗角、轻微冷暖 split-tone；锐度真实，人物肌肤质感写实
- 纹理：砖墙、鹅卵石、皮革、纸张、木纹细节清晰；雾、蒸汽、粉尘作为空气介质
- 构图：电影感三分构图、浅景深（人物/道具实，背景虚）、缓慢推拉摇移（Dolly / Pan / Tilt）

**B. 叙事基因（必须模仿）**
- 0–3 秒抛悬念（黑屏+心跳/事件切口），不做片头动画
- 每段：**场景建立 → 特写聚焦 → 反应/结果**三段式；镜头间因果咬合
- 数据锚点：时间、地点、人名、数字在旁白里明确出现
- 结尾：反转/升华 + 直接向观众提问，引导评论区

**C. 剪辑基因**
- 平均 3.3 秒/镜（参考视频实测 299 镜/991 秒）
- 本项目为控制成本与连贯性取 6.4 秒/镜，但每镜内部连续运镜 + 镜间溶解，观感不拖沓
- 同场景连续镜头必须保持**机位轴线一致、光线方向一致、服装道具一致**（连续性规则见第 6 节）

### 叙事主线（历史事实校准）
1. **钩子**：1888 年秋，伦敦东区白教堂；十一周，五名女性夜遇害；凶手自称 Jack the Ripper；百余年后无人知道他是谁。
2. **第一案 8·31**：巴克斯街（Buck's Row），马车夫发现玛丽·安·尼科尔斯，43 岁。
3. **第二案 9·8**：汉伯里街 29 号后院，安妮·查普曼；警督阿伯莱恩到场，围观者塞满巷子。
4. **信与名字 9·27**：中央新闻社收到红墨水信 "Dear Boss"，落款 Jack the Ripper；次日登上所有报纸。
5. **双重事件 9·30**：伯纳街（Berner St）斯特莱德 + 一英里外主教广场（Mitre Sq.）埃多斯；凶手穿过警戒区。当晚古尔斯顿街（Goulston St）涂鸦 + 血围裙碎片，警察总监沃伦下令天亮前擦掉。
6. **终案 11·9**：米勒庭院 13 号，玛丽·凯利；房东助手窗缝一瞥成为案件最不可言说处；此后杰克消失。
7. **嫌疑人 & DNA**：科斯明斯基 / 德鲁伊特 / 坦布尔蒂 / 西克特 / 王室传闻；2014 披肩 DNA 指向科斯明斯基但证据链存疑。
8. **收尾**：白教堂雾散，灯光换了，行人换了；只要五个名字被提起，他就还在灯照不到的地方——**他是谁？评论区说出你的推理。**

## 6. 逻辑审查规则（每次生成后逐项打勾，不通过即重拍）

### 6.1 历史事实（时间线）

- [ ] 第二案 1888-09-08，汉伯里街 29 号后院，安妮·查普曼，47 岁

## 8. 制作 SOP（本项目执行顺序）

1. 生成 28 张关键帧（写实电影风格，1080×1920，先做 S01/S04/S09/S14 四张风格校准）
2. 生成 10 段旁白（中文男声，云希/云健风格，每段按 N01–N10）
3. 引擎组装：关键帧 → 缓慢推/拉/摇 → 雾/雨/火光/煤灯闪烁粒子 → 胶片颗粒+暗角+split-tone → 溶解转场 → 字幕（白字黑边，距底 14%）→ 旁白+氛围合成音（风、雾笛、心跳、马蹄、印刷机、钟声）→ H.264 1080×1920 30fps
4. 自动 QC：全片解码、尺寸/帧率/帧数、黑场/冻结抽样、音量、旁白相关性、字幕安全宽度（沿用旧项目 check 逻辑）
5. 交付：MP4 + QC 报告 + 分镜时间线 + 本提示词文档
