# 脚本 / 文档上传区

这个文件夹是**脚本和文案的上传落地点**：网页上传区收到的每一份稿子都会原样存在这里，
文件名自动加时间戳（如 `20261006-120000_我的脚本.txt`），重名不覆盖，历史稿都留着。

## 怎么用

网页上传工具启动后，打开页面，把稿子拖进去，或直接粘进去：

```bash
python3 电影解说工具包/upload_text_server.py 8801
# 然后浏览器打开 http://localhost:8801
```

页面上有三种传法：

1. **拖文件**：把 txt / md / docx 拖进虚线框（可多选）
2. **点选文件**：点虚线框选文件
3. **直接粘贴**：把文字粘进下面的框，可以顺手给稿子起个名字（不填就按时间戳命名），
   `Ctrl / ⌘ + Enter` 直接保存

上传完成后，直接回到对话里说一句「脚本传好了」，我就能读到 `抖音文案/` 里的最新稿子，
按它继续往下做（分镜、口播稿、字幕、时长都按这份来）。

## 说明

* **支持**：`.txt .md .json .csv .srt .vtt .log .yml .yaml`，以及 Word 的 `.docx`
  （服务器自动抽出正文，存成同名 txt；表格按行保留）。单个最大 20 MB。
* **不支持**：`.pdf`、老版 `.doc`、图片扫描件 —— 请先「另存为 → txt / docx」，或直接把文字粘进框里。
* 编码自动识别（UTF-8 / UTF-8 BOM / GBK·GB18030 / Big5 / UTF-16），统一存成 UTF-8，
  Windows 记事本存的稿子不会乱码。
* 上传后会显示字数、行数、预计口播时长，方便卡抖音的时长。
* `上传记录.jsonl` 是每次上传的时间、字数、行数、原编码记录，删掉不影响使用。
