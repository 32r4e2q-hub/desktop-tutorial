# 部署照抄清单（Mistral 版 · 只用鼠标）

> 这份清单里**没有任何一处需要你贴 key 到聊天里**。key 只从你的浏览器进 Cloudflare 的 Secret 框。
> 对应代码说明见 [README.md](./README.md) 第 3′ 节。

---

## 第 1 步：确认你的 Mistral key 在

打开 https://console.mistral.ai/api-keys

- 看得到一条 key（形如 `[A-Za-z0-9]` 长串）→ 继续第 2 步
- 没有 → 点 `Create new key`，**当场复制**（Mistral 只显示一次）

顺手（可选，60 秒）：控制台左侧如果有 **Studio / Playground** 入口，在里面选 `mistral-small-latest`
随便问一句并运行。**这一步能单独证明"key 有效、额度可用"**，跟网关有没有部署无关。
如果 Studio 里跑不通，先别折腾部署——是 key/账号/额度的问题。

⚠️ 免费档（Experiment plan）限速约 **2 次/分钟**，1B tokens/月。撞到就返回 429，这是 Mistral 的
限制，不是网关坏了。想不撞墙就照第 4 步加第二个上游。

## 第 3 步：在 Cloudflare 建 Worker

1. 没账号先注册：https://dash.cloudflare.com/sign-up （邮箱+密码，**不要信用卡**）
2. 打开 https://dash.cloudflare.com/?to=/:account/workers-and-pages
3. `Create application` → 选 **Hello World** 模板 → 名字填 `zeroroute-lite` → `Deploy`
4. 进入这个 Worker → 点 **`Edit code`**
5. 编辑器里左侧文件 `worker.js` 的**内容全删**→ 粘贴第 2 步的内容 → **`Save and Deploy`**
   （只看到 Deploy 带下拉箭头时：选里面的 `Save`，回 Overview 再点 `Deploy`）

---

## 第 4 步：填 3 个框（决定安全与否）

路径：你的 Worker → **`Settings`** → **`Variables and Secrets`** → **`Add`**
→ **类型选 `Secret`**（不要选 Variable——Variable 在控制台里是明文可读的）

| 框里的名字（照抄，区分大小写） | 框里的值 |
|---|---|
| `MISTRAL_API_KEY` | 第 1 步那串 key |
| `ROUTER_API_KEY` | 你自己现编一串，如 30 个字母数字（用密码管理器的随机生成器）。**别复用任何现有密码** |
| `ADMIN_KEY` | **再编一个，必须和上面不同** |

填完点 **`Deploy`**。

（可选）想要"永不中断"真的成立，再加第二个上游——用你刚注册的 Cloudflare 就够，不用新账号：
1. https://dash.cloudflare.com/profile/api-tokens → 建一个 token，模板给 **Workers AI → Read & Edit** 权限
2. account id 在 Workers & Pages 页面右侧，形如 `a1b2c3...`
3. 再加 2 个 Secret：`CLOUDFLARE_API_KEY` = 那个 token，`CLOUDFLARE_ACCOUNT_ID` = account id

只有 1 个上游时，它一限速/一挂，网关只能返回 502——因为没地方可切。

---

## 第 5 步：验证（浏览器开两个链接就够）

地址在哪看：你的 Worker → **`Settings`** → **`Domains`**，形如
`https://zeroroute-lite.<你的子域>.workers.dev`

| 开这个 | 必须看到 | 看不到的意思 |
|---|---|---|
| `.../healthz` | `"mode": "authenticated"`；`mistral` 那行 `"enabled": true` | `enabled:false` → `MISTRAL_API_KEY` 名字打错了或没 Deploy |
| `.../v1/models` | **不带任何 key 打开必须报 401** | 报 200 → 你配错了，把 healthz 的 JSON 发我 |

再确认模型名：直接发一条消息（浏览器装个 POST 插件，或用任何 OpenAI 客户端）
`base_url = https://zeroroute-lite.<你的子域>.workers.dev/v1`，`api_key = 你第 4 步编的 ROUTER_API_KEY`，
`model = auto`。
如果返回里带 `mistral: model not found` → 回第 4 步加一个 Secret：`MISTRAL_MODEL=mistral-large-latest`
（或你在控制台模型列表里看到的任意一个）。

## 三条不许（我这边替你把关，你那边别破）

1. **不许把 key 贴进聊天、Issue、邮件、截图** —— 报错截图前扫一眼有没有 key 串。
2. **不许把 `ROUTER_API_KEY` 写进网页前端的 JS** —— 写了就是公开，谁都能烧你那 2 RPM。要挂到网站上，得由你自己的后端带着它转发；实在要开放，加 Secret `ALLOW_ANONYMOUS=true` 并把 `RATE_LIMIT_RPM=20`、`ALLOWED_ORIGINS=https://你的域名`，接受"别人能白用额度"这个前提。
3. **不许上生产/给别人用** —— 各家免费条款都禁止把免费 key 用于中转和生产，判滥用会封号。自用、演示、做实验没问题。
